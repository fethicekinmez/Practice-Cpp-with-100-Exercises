Exercise for reference: check whether the entered year is a leap year or not?


Answer:


#include <iostream>
using namespace std;

int main() {
    int year;
    cout << "Enter a year: ";
    cin >> year;
    
    if (year % 4 == 0 && year % 100 != 0 || year % 400 == 0) {
        cout << year << " is a leap year.";
    } else {
        cout << year << " is not a leap year.";
    }
    return 0;
}


Explanation:


  1. The if statement checks whether the year is a leap year or not. The condition inside the parentheses checks whether the year is divisible by 4 and not divisible by 100, or if it is divisible by 400.

  2. If the condition is true, the program outputs a message saying that the year is a leap year using the cout object.

  3. If the condition is false, the program outputs a message saying that the year is not a leap year using the cout object.
