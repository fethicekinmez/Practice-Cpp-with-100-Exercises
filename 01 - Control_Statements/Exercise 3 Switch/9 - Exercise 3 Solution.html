Exercise for reference: The program should display the name of the month corresponding to the input month number.


Answer:


#include <iostream>
using namespace std;

int main() {
    int month;

    // Input month number
    cout << "Enter month number (1-12): ";
    cin >> month;

    // Display month name
    switch (month) {
        case 1:
            cout << "January" << endl;
            break;
        case 2:
            cout << "February" << endl;
            break;
        case 3:
            cout << "March" << endl;
            break;
        case 4:
            cout << "April" << endl;
            break;
        case 5:
            cout << "May" << endl;
            break;
        case 6:
            cout << "June" << endl;
            break;
        case 7:
            cout << "July" << endl;
            break;
        case 8:
            cout << "August" << endl;
            break;
        case 9:
            cout << "September" << endl;
            break;
        case 10:
            cout << "October" << endl;
            break;
        case 11:
            cout << "November" << endl;
            break;
        case 12:
            cout << "December" << endl;
            break;
        default:
            cout << "Invalid month number" << endl;
    }

    return 0;
}


Explanation:

The program first declares an integer variable month to store the user input. It then prompts the user to enter a month number between 1 and 12 using the cout object and reads the input using the cin object.

The program then uses a switch statement to match the input month number to its corresponding month name. Each case statement checks whether the month variable matches the value of the month number and outputs the corresponding month name using the cout object. If the month variable does not match any of the case values, the default case is executed and the program outputs an "Invalid month number" message.

Finally, the program returns 0 to indicate successful execution.
