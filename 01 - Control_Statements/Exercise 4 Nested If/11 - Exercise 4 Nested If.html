Question: Write a program to find the largest among three numbers using nested if statement.


Expected output: The program should output the largest number among the three input numbers.


Enter three numbers: 
5 
9 
2

9 is the largest number

Hint:


  1. Use variables to store the three input numbers.

  2. Use the cin function to take input from the user.

  3. Use nested if statements to compare the three numbers and determine which one is the largest.

  4. Start by comparing the first two numbers using an if statement, and then compare the result to the third number using another if statement.

  5. Remember to handle cases where two or more numbers are equal.

  6. Use the cout function to output the result to the console.
