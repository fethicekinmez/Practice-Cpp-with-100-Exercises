Exercise for reference: Uses nested if statements to find the largest among three.


Answer:


#include <iostream>

using namespace std;

int main() {
    // take input from the user
    int num1, num2, num3;
    cout << "Enter three numbers: "<<endl;
    cin >> num1 >> num2 >> num3;

    // check which number is largest using nested if statements
    if (num1 >= num2) {
        if (num1 >= num3) {
            cout << num1 << " is the largest number";
        } else {
            cout << num3 << " is the largest number";
        }
    } else {
        if (num2 >= num3) {
            cout << num2 << " is the largest number";
        } else {
            cout << num3 << " is the largest number";
        }
    }

    return 0;
}


Explanation:


  1. First, the program declares three variables num1, num2, and num3 to store the three input numbers.

  2. The program then uses the cin function to take input from the user for the three numbers and stores them in the variables.

  3. The program then uses nested if statements to compare the three numbers and determine which one is the largest.

  4. The first if statement compares num1 and num2. If num1 is greater than or equal to num2, it enters the nested if statement. Otherwise, it enters the else block.

  5. In the nested if statement, the program checks if num1 is greater than or equal to num3. If it is, then num1 is the largest number. Otherwise, num3 is the largest number.

  6. If the first if statement determines that num2 is greater than num1, then the else block is entered. In this block, the program checks if num2 is greater than or equal to num3. If it is, then num2 is the largest number. Otherwise, num3 is the largest number.

  7. Finally, the program outputs the largest number using the cout function.
