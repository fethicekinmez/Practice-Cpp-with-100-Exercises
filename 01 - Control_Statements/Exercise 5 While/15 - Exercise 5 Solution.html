#include <iostream>
using namespace std;

int main() {
    int number;
    int sum = 0;

    // take input from the user
    cout << "Enter a number: ";
    cin >> number;

    while (number >= 0) {
        // add all positive numbers
        sum += number;

        // take input again if the number is positive
        cout << "Enter a number: ";
        cin >> number;
    }

    // display the sum
    cout << "\nThe sum is " << sum << endl;

    return 0;
}


Explanation:

The program first declares two integer variables, number and sum, and initializes sum to 0. It then prompts the user to enter a number and reads the input into the number variable using cin.

The program then enters a while loop that checks whether the value of number is non-negative. If it is, the program adds the value of number to sum, and prompts the user to enter another number. If the input number is negative, the while loop terminates, and the program outputs the sum of all the positive numbers entered using cout.

For example, if the user enters the following sequence of numbers: 3, 7, 1, -2, the program will output "The sum is 11".
