Exercise for reference: The program should display the name of the month corresponding to the input month number.


Answer:


#include <iostream>

using namespace std;

int main() {
    int i = 0;
    do {
        cout << i << "\n";
        i++;
    }
    while (i < 5);
    return 0;
}


Explanation:

The program initializes the variable i to 0, and then enters a do-while loop. Inside the loop, it prints the value of i to the console, followed by a newline character. It then increments the value of i by 1. The loop continues to execute as long as the value of i is less than 5.

On the first iteration, i is 0, so the program prints "0\n". It then increments i to 1, and checks whether i is less than 5. Since i is less than 5, the loop continues to execute. On the next iteration, i is 1, so the program prints "1\n". This process repeats until i is 4. On the fifth iteration, i is 4, so the program prints "4\n". It then increments i to 5, and checks whether i is less than 5. Since i is no longer less than 5, the loop terminates, and the program completes.
