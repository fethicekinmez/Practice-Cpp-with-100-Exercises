Exercise for reference: C++ program to check if a number is an Armstrong number.


Answer:


#include <iostream>
#include <cmath>
using namespace std;

int main() {
    int num, originalNum, remainder, n = 0;
    float result = 0.0;

    cout << "Enter an integer: ";
    cin >> num;

    originalNum = num;

    // count the number of digits
    while (originalNum != 0) {
        originalNum /= 10;
        ++n;
    }

    originalNum = num;

    // calculate the sum of nth power of each digit
    while (originalNum != 0) {
        remainder = originalNum % 10;
        result += pow(remainder, n);
        originalNum /= 10;
    }

    if (result == num)
        cout << num << " is an Armstrong number." << endl;
    else
        cout << num << " is not an Armstrong number." << endl;

    return 0;
}


Explanation:

In the above code, we first declare several integer and float variables to store the input number, the original number, the remainder, the number of digits, and the sum of the nth power of each digit.

We then prompt the user to enter an integer, and read the input using cin.

Next, we count the number of digits in the input number using a while loop. Inside the loop, we divide the original number by 10, and increment the number of digits by 1.

After counting the number of digits, we reset the value of the original number to the input number.

Next, we calculate the sum of the nth power of each digit in the input number using another while loop. Inside the loop, we calculate the remainder when the original number is divided by 10, and add the nth power of the remainder to the result. We then divide the original number by 10 to move to the next digit.

After calculating the sum of the nth power of each digit, we check if the result is equal to the input number using an if statement. If the result is equal to the input number, we output that the number is an Armstrong number. Otherwise, we output that the number is not an Armstrong number.
