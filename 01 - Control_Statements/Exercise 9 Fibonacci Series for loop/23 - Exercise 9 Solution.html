Exercise for reference: C++ program to generate the Fibonacci series up to n terms.


Answer:


#include <iostream>
using namespace std;

int main() {
    int n, t1 = 0, t2 = 1, nextTerm;

    cout << "Enter the number of terms: ";
    cin >> n;

    cout << "Fibonacci Series: ";

    for (int i = 1; i <= n; ++i) {
        cout << t1 << ", ";
        nextTerm = t1 + t2;
        t1 = t2;
        t2 = nextTerm;
    }

    return 0;
}


Explanation:

In the above code, we first declare several integer variables to store the input number, the first term, the second term, and the next term.

We then prompt the user to enter the number of terms, and read the input using cin.

Next, we output the message "Fibonacci Series: " to indicate the start of the series.

We then use a for loop to generate the Fibonacci series up to n terms. Inside the loop, we output the current term (which is initially the first term), and then calculate the next term as the sum of the previous two terms. We then update the values of the previous two terms to move to the next term.

After generating the series, the program terminates.
