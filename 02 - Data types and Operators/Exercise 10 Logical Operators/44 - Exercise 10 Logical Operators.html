Question: Write a C++ program to demonstrate the use of relational operators.


Expected output: The program Initializes values

int a=5, b=3, c=7, d=9;

Conditions:

!(a==0)

(a>b)&&(c<d)

(a<c)||(b<d)


a is not zero
Logical AND is true
Logical OR is true

Hint:

The program uses logical operators to evaluate conditions based on the values of the variables.

  • The ! symbol means "not", so !(a == 0) means "not (a equals 0)", which is equivalent to "a is not 0".

  • The && symbol means "and", so (a > b) && (c < d) is true only if both expressions are true.

  • The || symbol means "or", so (a < c) || (b < d) is true if either expression is true (or both).
