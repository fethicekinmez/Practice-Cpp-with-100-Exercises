Exercise for reference: The program uses logical operators to evaluate conditions based on the values of the variables.


Answer:


#include <iostream>
#include <string>
using namespace std;
 
int main()
{
  int a=5, b=3, c=7, d=9;
 
  if(!(a==0))
     cout<<"a is not zero"<<endl;
  else
    cout<<"a is zero"<<endl;
 
  if((a>b)&&(c<d))
        cout<<"Logical AND is true"<<endl;
  else
       cout<<"Logical AND is false"<<endl;
 
  if((a<c)||(b<d))
     cout<<"Logical OR is true"<<endl;
  else
     cout<<"Logical OR is false"<<endl;
}


Explanation:


  • The first condition !(a==0) checks if the value of a is not equal to zero. Since a is 10, the condition is true, and the message "a is not zero" is printed.

  • The second condition (a>b)&&(c<d) checks if both a is greater than b and c is less than d. Since both conditions are true (10 is greater than 8 and 12 is less than 14), the message "Logical AND is true" is printed.

  • The third condition (a<c)||(b<d) checks if either a is less than c or b is less than d. Since both conditions are true, the message "Logical OR is true" is printed.
