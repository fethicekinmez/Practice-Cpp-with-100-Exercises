#include <iostream>
using namespace std;

int main() {
   float principal, rate, time, interest;

   cout << "Enter principal amount: ";
   cin >> principal;

   cout << "Enter rate of interest: ";
   cin >> rate;

   cout << "Enter time (in years): ";
   cin >> time;

   // Calculate simple interest
   interest = (principal * rate * time) / 100;

   cout << "Simple interest = " << interest;

   return 0;
}


Explanation:


  1. We use the cout statement to display a message asking the user to enter the principal amount, and the cin statement to read the user's input from the console and store it in the principal variable. We do the same for the rate of interest and time, using the cout and cin statements to display messages and read input from the user.

  2. The next line of code calculates the simple interest using the formula (principal * rate * time) / 100. We store the result in the interest variable.

  3. Finally, we use the cout statement to display the simple interest to the user.
