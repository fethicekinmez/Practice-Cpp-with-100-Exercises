Exercise for reference: C++ program to find the average of three numbers.


Answer:


#include <iostream>
using namespace std;

int main() {
   float num1, num2, num3, average;

   cout << "Enter first number: ";
   cin >> num1;

   cout << "Enter second number: ";
   cin >> num2;

   cout << "Enter third number: ";
   cin >> num3;

   // Calculate average
   average = (num1 + num2 + num3) / 3;

   cout << "Average = " << average;

   return 0;
}


Explanation:

  1. We use the cout statement to display a message asking the user to enter the first number, and the cin statement to read the user's input from the console and store it in the num1 variable. We do the same for the second and third numbers, using the cout and cin statements to display messages and read input from the user.

  2. The next line of code calculates the average of the three numbers using the formula (num1 + num2 + num3) / 3. We store the result in the average variable.

  3. Finally, we use the cout statement to display the average to the user.
