Exercise for reference: C++ program to take input of three numbers and output the largest number using ternary operator.


Answer:


#include <iostream>
using namespace std;

int main() {
    int num1, num2, num3;
    cout << "Enter three numbers: ";
    cin >> num1 >> num2 >> num3;

    int largest = (num1 > num2) ? ((num1 > num3) ? num1 : num3) :
                  ((num2 > num3) ? num2 : num3);
    cout << "The largest number is " << largest << endl;

    return 0;
}


Explanation:

In this program, we will take input of three numbers from the user and compare them using the ternary operator to determine the largest one. We will use nested ternary operators to compare all three numbers and output the largest one. If the first number is the largest, we will output it. If the second number is larger than the first one, we will compare it with the third number. If the second number is also the largest, we will output it. Otherwise, we will output the third number as the largest.
