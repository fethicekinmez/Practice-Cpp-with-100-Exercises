Exercise for reference: C++ program to use bitwise operators left shift and right shift.


Answer:


#include <iostream>
using namespace std;

int main() {
  int num = 10;
  cout << "Original Number: " << num << endl;
  
  num = num << 2;
  cout << "Number after left shift: " << num << endl;
  
  num = num >> 3;
  cout << "Number after right shift: " << num << endl;

  return 0;
}


Explanation:

In the above code, we have initialized a variable num with the value of 10. We then print the original value of the number.

Next, we perform a left shift operation on the number by 2 positions, which means we shift the bits of the number to the left by 2 positions. The new value of num is then printed.

Finally, we perform a right shift operation on the number by 3 positions, which means we shift the bits of the number to the right by 3 positions. The new value of num is then printed.
