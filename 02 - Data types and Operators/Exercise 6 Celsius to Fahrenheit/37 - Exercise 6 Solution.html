Exercise for reference: C++ program to convert temperature from Celsius to Fahrenheit.


Answer:


#include <iostream>
using namespace std;

int main() {
  float tempC, tempF;

  cout << "Enter temperature in Celsius: ";
  cin >> tempC;

  // Convert Celsius to Fahrenheit
  tempF = (tempC * 9 / 5) + 32;

  cout << "Temperature in Fahrenheit: " << tempF << endl;

  return 0;
}


Explanation:

In the above code, we first declare two float variables tempC and tempF to store the temperature in Celsius and Fahrenheit, respectively.

We then prompt the user to enter the temperature in Celsius and read the input using cin.

Next, we convert the temperature from Celsius to Fahrenheit using the formula F = (C * 9/5) + 32 and store the result in the variable tempF.

Finally, we output the temperature in Fahrenheit using cout.
