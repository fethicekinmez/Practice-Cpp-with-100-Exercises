Exercise for reference: C++ program to demonstrate the use of relational operators.


Answer:


#include <iostream>
using namespace std;

int main() {
  int a = 11;
  int b = 5;

  cout << "a = " << a << ", b = " << b << endl;

  if (a == b) {
    cout << "a == b is true" << endl;
  }
  else {
    cout << "a == b is false" << endl;
  }

  if (a < b) {
    cout << "a < b is true" << endl;
  }
  else {
    cout << "a < b is false" << endl;
  }

  if (a > b) {
    cout << "a > b is true" << endl;
  }
  else {
    cout << "a > b is false" << endl;
  }

  return 0;
}


Explanation:

The program defines two integer variables a and b, with the values of a set to 11 and b set to 5. The program then demonstrates the use of relational operators to check if the following conditions are true or false:

  • a == b - checks if the value of a is equal to the value of b.

  • a < b - checks if the value of a is less than the value of b.

  • a > b - checks if the value of a is greater than the value of b.

The program outputs whether each condition is true or false.
