Question:Write a C++ program to print the right triangle star pattern, where each row of the triangle has one more star than the previous row, and the perpendicular line of the triangle is on the right side.


Expected output: 


Enter the number of rows: 5
    *
   **
  ***
 ****
*****

Hint:


  • You can use nested loops to print the pattern. The outer loop controls the number of rows, and the inner loops control the number of spaces and stars in each row.

  • To print spaces before the stars, you can use a nested loop that runs from 1 to the difference between the number of rows and the current row number. For example, if the user enters 5 as the number of rows and the current row is 3, you would need to print 5 - 3 = 2 spaces before the stars on this row.

  • To print the stars in each row, you can use another nested loop that runs from 1 to the current row number. For example, if the current row is 3, you would need to print 3 stars on this row.

  • To move to the next row, you can print a newline character after the inner loops are completed for the current row.
