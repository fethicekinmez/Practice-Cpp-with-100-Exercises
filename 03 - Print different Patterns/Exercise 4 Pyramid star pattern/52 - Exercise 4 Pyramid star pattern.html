Question: Write a C++ program to print the pyramid star pattern, where each row of the pyramid has an odd number of stars, and the perpendicular line of the pyramid is in the center.


Expected output: 


Enter the number of rows: 5
    *
   ***
  *****
 *******
*********

Hint:


  • You can use two nested loops to print the spaces and stars in each row of the pyramid. The outer loop controls the number of rows, and the inner loops control the number of spaces and stars in each row.

  • To print the spaces before the stars, you can use a nested loop that runs from 1 to the difference between the number of rows and the current row number. For example, if the user enters 5 as the number of rows and the current row is 3, you would need to print 5 - 3 = 2 spaces before the stars on this row.

  • To print the stars in each row, you can use another nested loop that runs from 1 to the current row number multiplied by 2 - 1. For example, if the current row is 3, you would need to print 2*3-1 = 5 stars on this row.

  • After the inner loops are completed for the current row, you can print a newline character to move to the next row.
