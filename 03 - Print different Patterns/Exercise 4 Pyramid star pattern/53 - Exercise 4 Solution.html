#include <iostream>
using namespace std;

int main() {
  int rows;
  cout << "Enter the number of rows: ";
  cin >> rows;

  // Outer loop to control the number of rows
  for (int i = 1; i <= rows; i++) {
    // Inner loop to print the spaces before the stars
    for (int j = 1; j <= rows - i; j++) {
      cout << " ";
    }
    // Inner loop to print the stars in each row
    for (int k = 1; k <= 2*i-1; k++) {
      cout << "*";
    }
    // Print a newline character to move to the next row
    cout << endl;
  }

  return 0;
}


Explanation:

The program uses a nested loop to print the pyramid star pattern. The outer loop runs from 1 to the number of rows entered by the user, and the inner loops print the appropriate number of spaces and stars in each row. The number of spaces decreases from the left to the right, while the number of stars increases from the center to the sides. After the inner loops are completed for the current row, the program prints a newline character to move to the next row.
