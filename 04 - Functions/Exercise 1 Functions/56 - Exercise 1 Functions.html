Question: Write a program that takes two integers as input from the user and then prints out their sum, difference, product, and quotient using separate functions for each operation.


Expected output: 


Enter the first integer: 10
Enter the second integer: 5
The sum is: 15
The difference is: 5
The product is: 50
The quotient is: 2

Hint:

You can use four separate functions to perform each operation. For example, the function to calculate the sum might look like this:


int add(int a, int b) {
    return a + b;
}
