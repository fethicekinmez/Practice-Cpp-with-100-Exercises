Exercise for reference: calculate the area of a circle and a rectangle using function return types:


Answer:


#include <iostream>
#include <cmath>

using namespace std;

double calculateCircleArea(double radius) {
    double area = M_PI * pow(radius, 2);
    //alternatively you can use area=3.14*radius*radius
    return area;
}

double calculateRectangleArea(double length, double width) {
    double area = length * width;
    return area;
}

int main() {
    double radius, length, width;
    
    cout << "Enter the radius of the circle: ";
    cin >> radius;
    double circleArea = calculateCircleArea(radius);
    cout << "The area of the circle is: " << circleArea << endl;
    
    cout << "Enter the length of the rectangle: ";
    cin >> length;
    cout << "Enter the width of the rectangle: ";
    cin >> width;
    double rectangleArea = calculateRectangleArea(length, width);
    cout << "The area of the rectangle is: " << rectangleArea << endl;
    
    return 0;
}


Explanation:

we first include the necessary header files to use iostream and cmath libraries. Then, we define two functions calculateCircleArea and calculateRectangleArea to calculate the area of the circle and rectangle, respectively. Both functions take in the necessary parameters and return the calculated area.

In the main function, we ask the user to enter the radius of the circle and the length and width of the rectangle using the cin function. We then call the respective functions to calculate the areas and print them using the cout function.

Note that we use the constant M_PI from the cmath library to represent the value of pi. Also, we use pow function to calculate the square of the radius of the circle.
