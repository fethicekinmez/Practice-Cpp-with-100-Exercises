Exercise for reference: Program to swap two numbers using call by value.
Answer:


#include <iostream>

using namespace std;

void swapNumbers(int a, int b) {
    int temp = a;
    a = b;
    b = temp;
}

int main() {
    int a = 5, b = 7;
    
    cout << "Before swapping:" << endl;
    cout << "a = " << a << endl;
    cout << "b = " << b << endl;
    
    swapNumbers(a, b);
    
    cout << "After swapping:" << endl;
    cout << "a = " << a << endl;
    cout << "b = " << b << endl;
    
    return 0;
}


Explanation:

In this code, we first include the necessary header files to use iostream library. Then, we define a function swapNumbers to swap the values of two numbers. The function takes two input arguments - the two numbers to be swapped - and swaps their values using a temporary variable. However, the changes made to a and b inside the swapNumbers function will not affect the original values of a and b in the main function.

In the main function, we declare two integer variables a and b and initialize them with the values 5 and 7. We then print the values of a and b using the cout function. We call the swapNumbers function to swap the values of a and b. Finally, we print the swapped values of a and b using the cout function. As we used call by value, the values of a and b in the main function remain unchanged after the function call.
