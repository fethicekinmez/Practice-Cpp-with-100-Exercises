Question: Write a C++ program to find the factorial of a given number using recursion.


Expected output: 


Enter a positive integer: 5
The factorial of 5 is 120

Hint:

Recursion is a technique in programming where a function calls itself with a smaller version of the problem it is trying to solve. The idea is to break down the original problem into smaller and simpler sub-problems until we reach a point where the sub-problem is so simple that we can solve it directly.

Recursion is often used when we need to perform the same set of operations on a problem that has a recursive structure. This means that the problem can be broken down into smaller problems of the same type.

For example, when we want to calculate the factorial of a number, we can break down the problem into a smaller sub-problem of finding the factorial of a smaller number. We keep doing this until we reach the base case, which is the factorial of 1, which is defined as 1. Once we have the solution to the base case, we can use it to solve the original problem.
