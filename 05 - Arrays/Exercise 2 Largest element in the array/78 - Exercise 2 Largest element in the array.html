Question: Write a C++ program to find the largest element in an array of integers.


Expected output:

For example, given the following array of integers:

int arr[] = {5, 8, 1, 9, 3};

The program should output:

The largest element in the array is: 9

Hint:

One approach to solving this problem is to initialize a variable to store the maximum value to the first element in the array. Then, loop through the array and compare each element to the maximum value, updating the maximum value as necessary.
