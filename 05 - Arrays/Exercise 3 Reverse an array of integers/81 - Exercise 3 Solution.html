Exercise for reference: The program should output the reversed array.


Answer:


#include <iostream>
using namespace std;

int main() {
   int arr[] = {1, 2, 3, 4, 5};
   int n = sizeof(arr) / sizeof(arr[0]);
   
   for (int i = 0; i < n/2; i++) {
      int temp = arr[i];
      arr[i] = arr[n-i-1];
      arr[n-i-1] = temp;
   }

   cout << "The reversed array is: ";
   for (int i = 0; i < n; i++) {
      cout << arr[i] << " ";
   }
   cout << endl;

   return 0;
}


Explanation:

  • The array arr is initialized with values 1, 2, 3, 4, 5.

  • The variable n is set to the size of the array, which is calculated by dividing the total size of the array by the size of each element.

  • The for loop starts from the first element of the array and iterates up to the middle element of the array, which is calculated as n/2.

  • Inside the for loop, the variable temp is used to store the value of the element at the current index.

  • The element at the current index is set to the value of the element at the corresponding index from the end of the array, which is calculated as n-i-1.

  • The element at the corresponding index from the end of the array is set to the value of the temp variable, which swaps the elements at the current index and its corresponding index from the end of the array.

  • After the for loop, the reversed array is printed to the console using another for loop that iterates over the array and prints each element separated by a space.

The end result is an array that has been reversed in place, meaning that no additional memory was required to store a separate reversed copy of the array.
