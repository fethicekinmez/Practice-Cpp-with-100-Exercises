Exercise for reference: sort an array of integers in ascending order


Answer:


#include <iostream>

using namespace std;

int main() {
    int arr[] = {3, 5, 1, 4, 2};
    int n = sizeof(arr) / sizeof(arr[0]);

    // Perform selection sort
    for (int i = 0; i < n - 1; i++) {
        int min_idx = i;
        for (int j = i + 1; j < n; j++) {
            if (arr[j] < arr[min_idx]) {
                min_idx = j;
            }
        }
        swap(arr[i], arr[min_idx]);
    }

    // Print the sorted array
    cout << "Sorted array in ascending order: ";
    for (int i = 0; i < n; i++) {
        cout << arr[i] << " ";
    }
    cout << endl;

    return 0;
}


Explanation:


  1. In this program, we define an array of integers and find its size.

  2. We then use the selection sort algorithm to sort the array in ascending order.

  3. Selection sort involves finding the minimum element in the unsorted portion of the array and swapping it with the first element of that portion.

  4. We continue this process until the entire array is sorted.

  5. Finally, we print the sorted array of integers in ascending order.
