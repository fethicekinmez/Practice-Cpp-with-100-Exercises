Exercise for reference: program that prints a string and finds its length without using any library functions


Answer:


#include <iostream>

using namespace std;

int main() {
  string str = "Welcome";
  int length = 0;
  
  // print the string
  cout << str << endl;
  
  // find the length of the string
  while (str[length] != '\0') {
    length++;
  }
  
  // print the length of the string
  cout << "Length of the string is: " << length << endl;
  
  return 0;
}


Explanation:

  • First, we declare a string variable str and initialize it with the string "Welcome".

  • Next, we declare an integer variable length and initialize it to 0.

  • We then use the cout statement to print the string to the console.

  • Next, we use a while loop to iterate through the string until the null character is reached. Inside the loop, we increment the length variable each time we encounter a character in the string.

  • After the loop, we use the cout statement to print the length of the string to the console.
