Question: Write a C++ program that uses a struct to store information about a book. The struct should have fields for the book's title, author, and publication year. Create a function that takes a reference to the book struct and prompts the user to input the information for the book. Then create another function that takes a reference to the book struct and displays the book's information.


Expected output:


Enter the book's title: The Great Gatsby
Enter the book's author: F. Scott Fitzgerald
Enter the book's publication year: 1925

Book information:
Title: The Great Gatsby
Author: F. Scott Fitzgerald
Publication year: 1925

Hint:


  1. Define the Book struct with fields for the book's title, author, and publication year.

  2. Write a function that takes a reference to a Book struct and prompts the user to enter the book's information. You can use the getline function to read the book's title and author, as it is better suited to handle inputs that contain spaces.

  3. Write a second function that takes a constant reference to a Book struct and displays the book's information in the console.

  4. In the main function, create a Book struct and call the function to prompt the user for the book's information.

  5. Finally, call the function to display the book's information in the console.
