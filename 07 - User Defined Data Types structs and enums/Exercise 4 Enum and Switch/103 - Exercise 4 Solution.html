Exercise for reference: The program should output a message based on the weather for the day entered by the user.


Answer:


#include <iostream>
using namespace std;

enum WeatherType {
    SUNNY,
    CLOUDY,
    RAINY,
    STORMY,
    SNOWY,
    FOGGY,
    WINDY
};

int main() {
    int dayNum;
    cout << "Enter a number between 1 and 7: ";
    cin >> dayNum;

    if (dayNum < 1 || dayNum > 7) {
        cout << "Invalid day number." << endl;
        return 1;
    }

    WeatherType weather;
    switch (dayNum) {
        case 1:
            weather = SUNNY;
            break;
        case 2:
            weather = CLOUDY;
            break;
        case 3:
            weather = RAINY;
            break;
        case 4:
            weather = STORMY;
            break;
        case 5:
            weather = SNOWY;
            break;
        case 6:
            weather = FOGGY;
            break;
        case 7:
            weather = WINDY;
            break;
    }

    switch (weather) {
        case SUNNY:
            cout << "It's a beautiful day. Enjoy the sunshine!" << endl;
            break;
        case CLOUDY:
            cout << "It's a little gloomy outside today." << endl;
            break;
        case RAINY:
            cout << "Don't forget your umbrella. It's going to rain today." << endl;
            break;
        case STORMY:
            cout << "Stay indoors if you can. There's a storm brewing." << endl;
            break;
        case SNOWY:
            cout << "Bundle up. It's cold and snowy outside." << endl;
            break;
        case FOGGY:
            cout << "Be careful on the roads. It's a foggy day today." << endl;
            break;
        case WINDY:
            cout << "Hold onto your hat. It's a windy day outside." << endl;
            break;
    }

    return 0;
}


Explanation:

  • First, the program prompts the user to input a number between 1 and 7 using the cout and cin statements.

  • The program then uses a switch statement to map the user's input to the corresponding day of the week using an enum value. If the input is invalid (i.e. not between 1 and 7), the program outputs an error message using cout.

  • Finally, the switch statement uses another switch statement to map the day of the week to the corresponding weather condition. The program outputs a message using cout that displays the day of the week and the weather condition for that day.
