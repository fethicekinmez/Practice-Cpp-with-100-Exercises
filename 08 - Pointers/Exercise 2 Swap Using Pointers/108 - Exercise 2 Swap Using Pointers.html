Question: Write a C++ program to swap two integer variables using pointers.


Expected output:

int x = 5;

int y = 10;


x = 10
y = 5

Hint:

  • Remember to use the dereference operator (*) when assigning or accessing values through the pointers.

  • You can declare the pointers separately and then assign them the memory addresses of the variables using the address-of operator (&).

  • To swap the values using pointers, you need to use a temporary variable to store the value of one of the variables before it is overwritten by the other variable's value.
