Exercise for reference: program to find the sum of two numbers using pointers.


Answer:


#include <iostream>
using namespace std;

int main() {
    int num1, num2, sum;
    int *ptr1, *ptr2;
    
    cout << "Enter first number: ";
    cin >> num1;
    cout << "Enter second number: ";
    cin >> num2;
    
    ptr1 = &num1;
    ptr2 = &num2;
    
    sum = *ptr1 + *ptr2;
    
    cout << "The sum of " << num1 << " and " << num2 << " is: " << sum << endl;
    
    return 0;
}


Explanation:

In this program, we declare two integer variables num1 and num2, and two pointers to integers ptr1 and ptr2. We then assign the addresses of the variables to the pointers using the address-of operator (&).

To add the values of the variables using pointers, we use the dereference operator (*) to access the values of the variables through the pointers. We then add the values and store the result in a separate integer variable sum.

The program should output the value of the sum variable, which is the sum of the two numbers.
