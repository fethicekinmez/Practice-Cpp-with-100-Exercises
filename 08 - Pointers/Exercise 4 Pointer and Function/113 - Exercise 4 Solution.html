Exercise for reference: The program to find the sum of an array using pointers and functions.


Answer:


#include <iostream>
using namespace std;

int sumArray(int *arr, int size) {
    int sum = 0;
    int *p = arr;
    
    for(int i = 0; i < size; i++) {
        sum += *(p + i);
    }
    
    return sum;
}

int main() {
    int size;
    cout << "Enter the size of the array: ";
    cin >> size;
    
    int arr[size];
    cout << "Enter the array elements: ";
    for(int i = 0; i < size; i++) {
        cin >> arr[i];
    }
    
    int sum = sumArray(arr, size);
    cout << "The sum of the array is: " << sum << endl;
    
    return 0;
}


Explanation:

In this program, we declare an integer array arr and a pointer to integers ptr. We also declare a variable size to store the size of the array.

We then define a function sumArray that takes two arguments - the array and its size. In the function, we use a pointer p to traverse the array and add the elements. We return the sum to the main function using the return statement.

In the main function, we call the sumArray function and pass the array and its size as arguments. We store the sum in a variable sum and output it.
