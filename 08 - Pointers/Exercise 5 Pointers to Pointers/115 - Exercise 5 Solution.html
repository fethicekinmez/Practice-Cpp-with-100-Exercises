Exercise for reference: The program should output the values of a variable using a pointer to pointer.

Answer:


#include <iostream>
using namespace std;

int main() {
    int num = 10;
    int *ptr = &num;
    int **pptr = &ptr;
    
    cout << "The value of num is: " << **pptr << endl;
    
    return 0;
}


Explanation:

In this program, we declare an integer variable num and initialize it with a value of 10. We then declare a pointer to the variable ptr and a pointer to the pointer pptr. We assign the address of the variable num to the pointer ptr and the address of the pointer ptr to the pointer to the pointer pptr.

We output the value of the variable num using the pointer to pointer pptr. We first dereference the pointer to pointer to get the pointer ptr, then dereference the pointer ptr to get the value of the variable num.
