Exercise for reference: Define a class called Rectangle with two private data members length and width. Define two public methods getArea and getPerimeter to calculate and return the area and perimeter of the rectangle, respectively. Define getArea inside the class definition and getPerimeter outside the class definition..


Answer:


#include <iostream>
using namespace std;

class Rectangle {
  private:
    int length;
    int width;

  public:
    Rectangle(int l, int w) {
      length = l;
      width = w;
    }

    int getArea() {
      return length * width;
    }

    int getPerimeter();
};

int Rectangle::getPerimeter() {
  return 2 * (length + width);
}

int main() {
  Rectangle rect(4, 5);
  cout << "Area: " << rect.getArea() << endl;
  cout << "Perimeter: " << rect.getPerimeter() << endl;
  return 0;
}


Explanation:

  • We define a class called Rectangle with two private data members length and width.

  • We define a public constructor to initialize the length and width data members when an object of the Rectangle class is created.

  • We define a public method called getArea inside the class definition to calculate and return the area of the rectangle using the formula length * width.

  • We declare a public method called getPerimeter inside the class definition, but we define it outside of the class definition to calculate and return the perimeter of the rectangle using the formula 2 * (length + width).

  • In the main function, we create an instance of the Rectangle object called rect with length=4 and width=5.

  • We call the getArea and getPerimeter methods on the rect object, which calculates and returns the area and perimeter of the rectangle, respectively.
