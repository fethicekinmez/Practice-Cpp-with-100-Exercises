Question: Write a C++ program to check whether a given integer is prime or not.


Expected output: The program should output whether the input integer is prime or not.


Enter a positive integer: 17
17 is a prime number

Hint:

A prime number is a positive integer that is only divisible by 1 and itself. A simple way to check whether a number is prime is to loop through all the numbers from 2 to the number's square root, and check whether the number is divisible by any of these numbers.
