Exercise for reference: C++ program to check whether a given integer is prime or not.


Answer:


#include <iostream>

using namespace std;

int main()
{
   int num;
   bool isPrime = true;

   cout << "Enter a positive integer: ";
   cin >> num;

   for(int i = 2; i <= num / 2; i++)
   {
      if(num % i == 0)
      {
         isPrime = false;
         break;
      }
   }

   if(isPrime)
      cout << num << " is a prime number";
   else
      cout << num << " is not a prime number";

   return 0;
}


Explanation:

We start by taking the input integer from the user. We then loop through all the numbers from 2 to num/2 (since a number cannot have a factor greater than its half). If any number divides the input integer evenly (i.e. the remainder is 0), then we know that the input integer is not prime. We set the isPrime boolean variable to false and break out of the loop.

If after the loop, isPrime is still true, then we know that the input integer is prime.
