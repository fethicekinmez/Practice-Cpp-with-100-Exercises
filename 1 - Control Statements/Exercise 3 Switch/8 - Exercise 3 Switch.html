Question: Write a C++ program to read a month number and display the corresponding month name using a switch case statement.


Expected output::


Enter month number (1-12): 5
May

Hint:

  1. Declare an integer variable month to store the input month number.

  2. Prompt the user to enter the month number using the cout statement and read the input using the cin statement.

  3. Use the switch case statement to check the value of the input month variable.

  4. In each case, display the name of the month using the cout statement and the corresponding month number.

  5. Use the default case to display an error message if the input month number is not valid.
