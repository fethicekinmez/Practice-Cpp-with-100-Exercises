Exercise for reference: program in C++ to print sum of odd no between 0 to 10 using continue.


Answer:


#include <iostream>
using namespace std;

int main() {
  int sum = 0;
  
  for(int i = 0; i <= 10; i++) {
    if(i % 2 == 0) {
      continue; // Skip even numbers
    }
    sum += i; // Add odd numbers to sum
  }

  cout << "Sum of odd numbers between 0 and 10: " << sum << endl;

  return 0;
}


Explanation:

In the above code, we first declare an integer variable sum to store the sum of odd numbers.

We then use a for loop to iterate over the numbers between 0 and 10. Inside the loop, we use an if statement to check if the current number is even using the modulo operator. If the number is even, we skip it using the continue statement.

Otherwise, we add the current number to the sum variable.

Finally, we output the sum of odd numbers between 0 and 10 using cout.
