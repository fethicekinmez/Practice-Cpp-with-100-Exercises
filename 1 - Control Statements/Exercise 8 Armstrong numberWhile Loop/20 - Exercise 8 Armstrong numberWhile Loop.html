Question: Write a C++ program to check if a number is an Armstrong number.


Expected output: The program should output whether the input number is an Armstrong number or not.


Enter an integer: 153
153 is an Armstrong number.

Hint:

An Armstrong number is a number that is equal to the sum of the nth power of its digits, where n is the number of digits in the number. To check if a number is an Armstrong number, you need to count the number of digits, and then calculate the sum of the nth power of each digit.
