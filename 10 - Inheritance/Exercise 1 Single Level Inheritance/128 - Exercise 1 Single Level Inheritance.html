Question: Create a C++ program that demonstrates single level inheritance using a class hierarchy of vehicles

Expected output:

Vehicle Details:
Make: Toyota
Model: Camry
Year: 2022

Car Details:
Make: Toyota
Model: Camry
Year: 2022
Number of Doors: 4

Hint:

Create a base class called "Vehicle" with private member variables for the vehicle's make, model, and year, and a public member function for printing the vehicle's details. Create a derived class called "Car" that inherits from the "Vehicle" class and has a private member variable for the car's number of doors, and a public member function for printing the car's details. Use inheritance to access the base class's member variables and member function in the derived class.

Remember to use the public keyword when defining the member functions in the derived classes, so that they are accessible outside of the class. Also, use the protected keyword when defining the member variables in the base class, so that they are accessible in the derived classes.
