Question: Create a C++ program that demonstrates multilevel inheritance using a class hierarchy of animals.

Expected output:


Animal Details:
Name: Daisy
Species: Cow

Mammal Details:
Name: Daisy
Species: Cow
Number of Legs: 4

Dog Details:
Name: Rusty
Species: Dog
Number of Legs: 4
Breed: Labrador

Hint:

Create a base class called "Animal" with private member variables for the animal's name and species, and a public member function for printing the animal's details. Create a derived class called "Mammal" that inherits from the "Animal" class and has a private member variable for the mammal's number of legs, and a public member function for printing the mammal's details. Create another derived class called "Dog" that inherits from the "Mammal" class and has a private member variable for the dog's breed, and a public member function for printing the dog's details. Use multilevel inheritance to access the base class's member variables and member function in the derived classes.

Remember to use the public keyword when defining the member functions in the derived classes, so that they are accessible outside of the class. Also, use the protected keyword when defining the member variables in the base class, so that they are accessible in the derived classes.
