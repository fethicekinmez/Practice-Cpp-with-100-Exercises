Exercise for reference: Create a C++ program that demonstrates multilevel inheritance using a class hierarchy of animals

#include <iostream>
using namespace std;

class Animal {
  protected:
    string name;
    string species;
  public:
    Animal(string nm, string sp) {
      name = nm;
      species = sp;
    }
    void printDetails() {
      cout << "Animal Details:\n";
      cout << "Name: " << name << endl;
      cout << "Species: " << species << endl;
    }
};

class Mammal: public Animal {
  private:
    int numLegs;
  public:
    Mammal(string nm, string sp, int legs): Animal(nm, sp) {
      numLegs = legs;
    }
    void printDetails() {
      Animal::printDetails();
      cout << "\nMammal Details:\n";
      cout << "Number of Legs: " << numLegs << endl;
    }
};

Explanation:

The program creates a class hierarchy of animals using multilevel inheritance. The base class Animal has private member variables name and species, and a public member function printDetails() for printing the animal's details. The derived class Mammal inherits from the Animal class and has a private member variable numLegs, and a public member function printDetails() for printing the mammal's details. The derived class Dog inherits from the Mammal class and has a private member variable breed, and a public member function printDetails() for printing the dog's details. The derived classes access the name, species, and printDetails() member function from the base class using multilevel inheritance.
