Question: Create a C++ program that demonstrates multiple inheritance using a class hierarchy of a vehicle


Expected output:

Engine Details:
Fuel Type: Gasoline

Wheels Details:
Number of Wheels: 4

Car Details:
Brand: Ford
Fuel Type: Gasoline
Number of Wheels: 4

Hint:

Create a base class called "Engine" with a private member variable for the engine's fuel type, and a public member function for printing the engine's details. Create another base class called "Wheels" with a private member variable for the number of wheels, and a public member function for printing the wheel's details. Create a derived class called "Car" that inherits from both the "Engine" and "Wheels" classes and has a private member variable for the car's brand, and a public member function for printing the car's details. Use multiple inheritance to access the member variables and member functions from both base classes in the derived class.
