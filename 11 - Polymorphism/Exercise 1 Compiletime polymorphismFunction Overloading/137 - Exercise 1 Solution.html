Exercise for reference: The program should output the sum of the two integers and the sum of the two floats, respectively.

Answer:


#include <iostream>
using namespace std;

int sum(int a, int b) {
    return a + b;
}

float sum(float a, float b) {
    return a + b;
}

int main() {
    int x, y;
    float p, q;

    cout << "Enter two integers: ";
    cin >> x >> y;

    cout << "Enter two floats: ";
    cin >> p >> q;

    cout << "Sum of integers: " << sum(x, y) << endl;
    cout << "Sum of floats: " << sum(p, q) << endl;

    return 0;
}


Explanation:

Compile-time polymorphism is a mechanism by which a program can have multiple functions with the same name, but different argument lists, and the correct function is called based on the types of arguments passed to it at compile-time. This is achieved through function overloading, which is the ability to define multiple functions with the same name but different argument lists.

In C++, function overloading is determined by the number, type, and order of the arguments passed to a function. When a function call is made, the compiler looks for a function with the same name and the same number of arguments as the function call. If such a function is found, the compiler checks if the types of the arguments match the parameter types of the function. If there is a match, the function is called. Otherwise, the compiler tries to find another function with the same name and number of arguments, and repeats the process until a match is found or all functions have been checked.

In the example code provided, the program defines two functions with the same name sum, but different parameter lists - one that accepts two integers, and another that accepts two floats. When the program calls sum with two integers or two floats, the correct function is called based on the types of the arguments passed to it.

Overall, compile-time polymorphism is a useful feature in C++ that allows for more flexible and concise code by allowing multiple functions with the same name, but different parameter lists, to be defined in a program.
