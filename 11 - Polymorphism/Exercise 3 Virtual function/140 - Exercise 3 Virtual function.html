Question: Write a C++ program that demonstrates the use of virtual functions

Expected output:


Dog says: Woof!
Cat says: Meow!

Hint:

Define a base class Animal with a virtual function makeSound(). Derive two classes Dog and Cat from the Animal class, and override the makeSound() function in each derived class to output a different sound for each animal. In the main program, create objects of each class and call the makeSound() function on each object.

Virtual functions are a powerful feature of C++ that allow functions in derived classes to be called through a pointer or reference to the base class object. This can be used to implement run-time polymorphism, which enables different objects of the same base class to behave differently based on their actual type. To declare a virtual function, use the virtual keyword in the function declaration in the base class.
