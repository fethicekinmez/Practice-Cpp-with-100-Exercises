Exercise for reference: The program should output the sound of a dog and a cat, respectively, based on the objects that were created.


Answer:


#include <iostream>
using namespace std;

class Animal {
public:
    virtual void makeSound() {
        cout << "Unknown animal sound" << endl;
    }
};

class Dog : public Animal {
public:
    void makeSound() {
        cout << "Woof!" << endl;
    }
};

class Cat : public Animal {
public:
    void makeSound() {
        cout << "Meow!" << endl;
    }
};

int main() {
    Animal *a1 = new Dog();
    Animal *a2 = new Cat();

    a1->makeSound();
    a2->makeSound();

    delete a1;
    delete a2;

    return 0;
}


Explanation:

In the example code provided, we define a base class Animal with a virtual function makeSound(), which outputs a sound that the animal makes. We then derive two classes Dog and Cat from the Animal class and override the makeSound() function in each derived class to output a different sound for each animal.

In the main program, we create objects of each class and call the makeSound() function on each object through a pointer to the base class. Since the makeSound() function is declared as virtual in the Animal class, the correct version of the function is called at run-time based on the actual type of object being referred to. This is an example of polymorphism using virtual functions.
