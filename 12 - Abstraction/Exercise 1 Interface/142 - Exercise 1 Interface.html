Question: Write a C++ program that demonstrates the use of an interface to achieve abstraction.

Expected output:


Rectangle Area: 12
Rectangle Perimeter: 14
Circle Area: 78.5398
Circle Perimeter: 31.4159

Hint:

Define an interface Shape with pure virtual functions area() and perimeter(). Derive two classes Rectangle and Circle from the Shape interface and implement the virtual functions in each derived class to calculate the area and perimeter of the respective shapes. In the main program, create objects of each class and call the area() and perimeter() functions on each object.

An interface in C++ is a class that contains only pure virtual functions. Pure virtual functions are functions that have no implementation and are declared with the = 0 syntax in the function declaration. An interface can be used to achieve abstraction, which allows a programmer to focus on the behavior of an object rather than its implementation. To derive a class from an interface, use the class Derived : public Base syntax.
