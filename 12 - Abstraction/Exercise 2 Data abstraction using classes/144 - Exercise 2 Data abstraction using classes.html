Question: Write a C++ program to illustrate data abstraction using classes

Expected output:

The program should prompt the user to enter two numbers and then display their sum.


Enter two numbers: 10 20
Sum of two number is: 30

Hint:

Data abstraction is a programming technique that involves hiding the implementation details of a class from the outside world and exposing only the essential features of the class. In this example, we define a class called Sum that has private variables x, y, and z, and a public method called add that allows the user to input two numbers and computes their sum.
