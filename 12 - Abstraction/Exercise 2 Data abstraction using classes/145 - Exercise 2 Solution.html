Exercise for reference: The program should prompt the user to enter two numbers and then display their sum.

Answer:


#include <iostream>    
using namespace std;    
class Sum    
{    
private:
    int x, y, z; // private variables  
public:    
    void add()    
    {    
        cout<<"Enter two numbers: ";    
        cin>>x>>y;    
        z = x + y;    
        cout<<"Sum of two number is: "<<z<<endl;    
    }    
};    

int main()    
{    
    Sum sm;    
    sm.add();    
    return 0;    
}


Explanation:

In this program, we define a class called Sum that has three private variables x, y, and z. The add() method is a public member function of the Sum class that allows the user to input two numbers x and y and then computes their sum, which is stored in the variable z. The main() function creates an object of the Sum class called sm and calls the add() method of the object.
