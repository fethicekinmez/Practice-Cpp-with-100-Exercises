Question: Write a C++ program that prompts the user to input two integers and then divides the first number by the second number. Use exception handling to catch the divide-by-zero exception and display an error message to the user.


Expected output:


Enter the first number: 10
Enter the second number: 0
Exception: Divide by zero error!

Hint:

In C++, you can use a try-catch block to handle exceptions. Inside the try block, you can perform the operation that may throw an exception. If an exception is thrown, the program control is transferred to the catch block, where you can handle the exception.
