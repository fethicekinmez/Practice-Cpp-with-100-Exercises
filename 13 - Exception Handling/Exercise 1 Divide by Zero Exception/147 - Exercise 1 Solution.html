Exercise for reference: The program should prompt the user to input two integers and then divide the first number by the second number. If the second number is zero, the program should catch the divide-by-zero exception and display an error message to the user.


Answer:


#include <iostream>
using namespace std;

int main()
{
    int num1, num2, result;
    cout << "Enter the first number: ";
    cin >> num1;
    cout << "Enter the second number: ";
    cin >> num2;

    try {
        if (num2 == 0)
            throw "Divide by zero error!";
        result = num1 / num2;
        cout << "Result: " << result << endl;
    }
    catch (const char* msg) {
        cerr << "Exception: " << msg << endl;
    }
    return 0;
}


Explanation:

In this program, we prompt the user to input two integers and then divide the first number by the second number. If the second number is zero, the program throws a divide-by-zero exception. We use a try-catch block to handle this exception and display an error message to the user.
