Question: Write a C++ program that prompts the user to input a positive integer. Use exception handling to catch the invalid input exception if the user enters a negative integer or a non-integer value, and display an error message to the user.

Expected output:


Enter a positive integer: -5
Exception: Invalid input: Please enter a positive integer.

Hint:

The program should prompt the user to input a positive integer. If the user enters a negative integer or a non-integer value, the program should catch the invalid input exception and display an error message to the user. If the user enters a valid positive integer, the program should display a message indicating that the input is valid.
