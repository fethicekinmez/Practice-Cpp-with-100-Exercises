Exercise for reference: program that prompts the user to input a positive integer. Use exception handling to catch the invalid input exception if the user enters a negative integer or a non-integer value, and display an error message to the user.


Answer:


#include <iostream>
using namespace std;

int main()
{
    int num;
    cout << "Enter a positive integer: ";
    cin >> num;

    try {
        if (num <= 0)
            throw "Invalid input: Please enter a positive integer.";
        else if (cin.fail())
            throw "Invalid input: Please enter an integer.";
        cout << "Valid input: " << num << endl;
    }
    catch (const char* msg) {
        cerr << "Exception: " << msg << endl;
    }

    return 0;
}


Explanation:

This program prompts the user to input a positive integer and uses exception handling to catch invalid input. We first read the input using cin. We then use a try-catch block to catch the exceptions. If the input is less than or equal to zero, we throw an exception with a custom error message. If the input is not an integer, we also throw an exception with a custom error message. If no exception is thrown, we print a message indicating that the input is valid.
