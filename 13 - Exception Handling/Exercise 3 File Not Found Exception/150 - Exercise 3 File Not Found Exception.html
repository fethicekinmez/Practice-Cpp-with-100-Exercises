Question: Write a C++ program that reads data from a file. Use exception handling to catch the file not found exception if the file does not exist and display an error message to the user.

Expected output:


Enter filename: test.txt
Exception: File not found.

Hint:

In C++, you can use the ifstream class to read data from a file. If the file does not exist, the is_open() function returns false, which you can check using an if statement. If the file is not found, you can throw an exception with a custom error message.
