Exercise for reference: program that reads data from a file. Use exception handling to catch the file not found exception if the file does not exist and display an error message to the user.


Answer:


#include <iostream>
#include <fstream>
using namespace std;

int main()
{
    string filename;
    cout << "Enter filename: ";
    cin >> filename;

    ifstream infile;
    infile.open(filename);

    try {
        if (!infile.is_open())
            throw "File not found.";
        // read data from file
        cout << "Data read from file." << endl;
        infile.close();
    }
    catch (const char* msg) {
        cerr << "Exception: " << msg << endl;
    }

    return 0;
}


Explanation:

This program prompts the user to enter the filename and uses exception handling to catch the file not found exception. We first read the filename using cin. We then create an ifstream object and open the file using the open() function. We then use a try-catch block to catch the exceptions. If the file is not found, we throw an exception with a custom error message. If the file is found, we read data from the file and print a message indicating that the data has been read.
