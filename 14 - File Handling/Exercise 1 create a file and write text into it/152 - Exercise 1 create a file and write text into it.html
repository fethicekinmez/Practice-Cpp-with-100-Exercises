Question: Write a C++ program to create a file and write some text into it.

Expected output: The program should create a file named example.txt in the current directory and write the text "Hello, World!" into it. It should then print a message indicating that the file was created and the text was written successfully.


File created and text written successfully.

Hint:

To create a file in C++, you can use the ofstream class. You need to open the file using the open() function and specify the filename and the file mode (in this case, we want to write to the file, so we use the ofstream::out flag). Once the file is open, you can write text to it using the << operator. Finally, you should close the file using the close() function.
