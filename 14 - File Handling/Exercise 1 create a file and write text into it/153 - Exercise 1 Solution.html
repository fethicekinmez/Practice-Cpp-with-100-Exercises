Exercise for reference: program to create a file and write some text into it.

Answer:


#include <iostream>
#include <fstream>
using namespace std;

int main() {
    ofstream outfile;
    outfile.open("example.txt");

    if (!outfile) {
        cerr << "Error: Unable to create file!" << endl;
        return 1;
    }

    outfile << "Hello, World!" << endl;
    outfile.close();

    cout << "File created and text written successfully." << endl;
    return 0;
}


Explanation:

This program creates a file named example.txt and writes the text "Hello, World!" to it. It first creates an ofstream object named outfile and opens the file using the open() function. If the file cannot be opened, the program prints an error message and returns an error code. Otherwise, the program writes the text "Hello, World!" to the file using the << operator and closes the file using the close() function. Finally, it prints a message indicating that the file was created and the text was written successfully.
