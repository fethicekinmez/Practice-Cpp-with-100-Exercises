Question: Write a C++ program to read the contents of a file and display them on the screen


Expected output:

Suppose we have a file named "example.txt" with the following contents:

This is an example file.
It contains some text.


When we run the program with "example.txt" as the input file, the output will be:

This is an example file.
It contains some text.

Hint:

Make sure that the file you want to read is located in the same directory as your program. If the file is located in a different directory, you will need to specify the full path to the file.
