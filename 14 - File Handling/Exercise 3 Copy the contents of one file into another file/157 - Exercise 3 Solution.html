Exercise for reference: program to copy the contents of one file into another file


Answer:


#include <iostream>
#include <fstream>

using namespace std;

int main() {
    ifstream input_file("input.txt");
    ofstream output_file("output.txt");
    char c;

    if (input_file.is_open() && output_file.is_open()) {
        while (input_file.get(c)) {
            output_file << c;
        }
        cout << "File copied successfully." << endl;
        input_file.close();
        output_file.close();
    } else {
        cout << "Unable to open file." << endl;
    }

    return 0;
}


Explanation:

In this program, we use the ifstream and ofstream classes to read from one file and write to another file. We open the input file "input.txt" using ifstream input_file("input.txt") and the output file "output.txt" using ofstream output_file("output.txt").


We then check if both files are open using input_file.is_open() and output_file.is_open(). If both files are open, we read each character from the input file using input_file.get(c) and write it to the output file using output_file << c. We repeat this process until we have read all the characters in the input file.


Once the copying is complete, we display a success message using cout << "File copied successfully." << endl; and close both files using input_file.close() and output_file.close().


If either file cannot be opened, we display an error message using cout << "Unable to open file." << endl;.


To use this program, you need to replace "input.txt" with the name of the file you want to copy from and "output.txt" with the name of the file you want to copy to.
