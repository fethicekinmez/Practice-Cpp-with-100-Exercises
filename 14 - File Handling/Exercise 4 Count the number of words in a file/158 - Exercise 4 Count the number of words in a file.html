Question: Write a C++ program that demonstrates compile-time polymorphism using function overloading.

Expected output:


Enter the filename: myfile.txt

This is a sample file.

It contains some text.

The text has multiple lines.

Each line has some of words.

The file contains 20 words.

Hint:

  2. Before you can count the words in the file, you need to open it using the ifstream class. Make sure to use the correct syntax to open the file and check if it was opened successfully using the is_open() function.

  3. To count the number of words in the file, you can use a loop to read each word using the >> operator and increment a counter for each word.

  4. Be careful when counting words, as certain characters (such as punctuation) may be included as part of a word. You may want to consider removing these characters before counting the words.

  5. Finally, remember to close the file once you're done using it using the close() function.
