Exercise for reference: program that counts the number of words in a file

Answer:


#include <iostream>
#include <fstream>
#include <string>

using namespace std;

int main()
{
    // Open the file
    string filename;
    cout << "Enter the filename: ";
    cin >> filename;
    ifstream infile(filename);

    // Check if the file is open
    if (!infile.is_open())
    {
        cout << "Error opening file." << endl;
        return 0;
    }

    // Count the number of words
    int count = 0;
    string word;
    while (infile >> word)
    {
        count++;
    }

    // Print the number of words
    cout << "The file contains " << count << " words." << endl;

    // Close the file
    infile.close();

    return 0;
}


Explanation:

  1. The program prompts the user to enter the name of the file.

  2. The program opens the file using the ifstream class.

  3. If the file fails to open, the program displays an error message and exits.

  4. The program reads each word in the file using the >> operator.

  5. For each word, the program increments a counter.

  6. Once the program has read all the words, it prints the number of words.

  7. Finally, the program closes the file.
