Question: Write a C++ program to sort the contents of a file alphabetically

Expected output:

Let's say we have an input file "input.txt" with the following content:


apple
orange
banana
grape
pear


The program should read this file, sort the lines alphabetically, and write the sorted lines to another file "output.txt". Here is the expected output in "output.txt":



apple
banana
grape
orange
pear

Hint:


  1. Open the input and output files using fstream.

  2. Use a vector or an array to store the lines from the input file.

  3. Use a loop to read the lines from the input file and store them in the vector or array.

  4. Sort the lines using a bubble sort or selection sort algorithm.

  5. Write the sorted lines to the output file.
