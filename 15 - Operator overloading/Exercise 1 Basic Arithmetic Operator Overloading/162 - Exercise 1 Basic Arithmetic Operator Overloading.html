Question: Write a C++ program that demonstrates operator overloading:

Expected output:


v1 + v2 = (5, 7, 9)
v2 - v1 = (3, 3, 3)
v1 * 3 = (3, 6, 9)

Hint:

When you overload an operator, you can define what it means for two objects of your class to be added, subtracted, multiplied, or divided. In this program, the Vector class has overloaded the +, -, and * operators to add, subtract, and multiply vectors, respectively

The output is obtained by adding, subtracting, and multiplying the vectors defined in the main function, and then printing out the resulting vectors.
