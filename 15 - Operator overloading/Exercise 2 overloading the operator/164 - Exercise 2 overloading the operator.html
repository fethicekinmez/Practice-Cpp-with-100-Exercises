Question: Write a C++ program to overload the increment operator ++ and decrement operator --

Expected output:


The initial count is: 0
After incrementing, the count is: 1
After decrementing, the count is: 0

Hint:

Create a custom class called Counter. The Counter class should have a private integer variable count and public member functions to get the count, set the count, and display the count. The increment operator should increase the count by 1, and the decrement operator should decrease the count by 1.

To overload the increment operator ++, you can define a member function with the signature Counter& operator++(). This function should increase the count by 1 and return a reference to the Counter object.

To overload the decrement operator --, you can define a member function with the signature Counter& operator--(). This function should decrease the count by 1 and return a reference to the Counter object.
