Question: Write a C++program to swap two values using a template function.


Expected output:


Before swapping:
int values: 5, 10
double values: 3.14, 6.28
char values: a, b
After swapping:
int values: 10, 5
double values: 6.28, 3.14
char values: b, a

Hint:

  • Use a template function to create a general swap function that can be used for any data type.

  • Pass the two values that need to be swapped as references to the function.

  • Create a temporary variable to store one of the values.

  • Assign the first value to the second value.

  • Assign the temporary variable to the first value.

In this way, the values will be swapped using the same code, regardless of the data type.
