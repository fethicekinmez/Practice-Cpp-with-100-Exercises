Exercise for reference: The program to swap two values using a template function:

Answer:


#include <iostream>
using namespace std;

template<typename T>
void swapValues(T& value1, T& value2) {
    T temp = value1;
    value1 = value2;
    value2 = temp;
}

int main() {
    int intVal1 = 5, intVal2 = 10;
    double doubleVal1 = 3.14, doubleVal2 = 6.28;
    char charVal1 = 'a', charVal2 = 'b';

    cout << "Before swapping:" << endl;
    cout << "int values: " << intVal1 << ", " << intVal2 << endl;
    cout << "double values: " << doubleVal1 << ", " << doubleVal2 << endl;
    cout << "char values: " << charVal1 << ", " << charVal2 << endl;

    swapValues(intVal1, intVal2);
    swapValues(doubleVal1, doubleVal2);
    swapValues(charVal1, charVal2);

    cout << "After swapping:" << endl;
    cout << "int values: " << intVal1 << ", " << intVal2 << endl;
    cout << "double values: " << doubleVal1 << ", " << doubleVal2 << endl;
    cout << "char values: " << charVal1 << ", " << charVal2 << endl;

    return 0;
}


Explanation:

The program defines a template function named swapValues that takes two references of type T as input parameters. The function uses a temporary variable of type T to swap the values of the two input parameters.

In the main function, two variables x and y are defined, one of type int and the other of type double. The initial values of x and y are printed on the console. Then, the swapValues function is called twice, once with x and y as input parameters, and once with a and b as input parameters. After each call to swapValues, the new values of the variables are printed on the console.

The output of the program shows that the values of x and y have been swapped, as well as the values of a and b. This demonstrates the flexibility of the template function, as it can be used with different data types.
