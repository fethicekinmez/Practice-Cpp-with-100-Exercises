Expected output:


3

Hint:

When implementing a template class in C++, be sure to include the entire implementation in the header file. This is because template classes cannot be split into separate header and implementation files like regular classes. Additionally, when using a vector as the underlying data structure for the stack, remember to use the back() method to access the top element and the pop_back() method to remove the top element from the vector.
