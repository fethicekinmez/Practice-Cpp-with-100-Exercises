Question: Create a template function that can calculate the average of any number of values. The function should take a variable number of arguments.


Expected output:


Average of 2, 4, 6, 8, 10: 6
Average of 1.2, 3.4, 5.6, 7.8: 4.5
Average of -3, -1, 1, 3: 0

Hint:

  1. The program uses templates to create a function named average that can calculate the average of any number of values.

  2. The function average takes a variable number of arguments using variadic templates.

  3. The first version of the average function is a base case that returns the first argument itself.

  4. The second version of the average function is a recursive case that calculates the average of all the arguments by adding the first argument and recursively calling the function with the remaining arguments, and finally dividing the sum by the total number of arguments.

  5. The program demonstrates the usage of the average function by calling it with different types of arguments (int, double) and different number of arguments.
