Exercise for reference: Create a template function that can calculate the average of any number of values.

Answer:


#include <iostream>
using namespace std;

template<typename T>
T average(T arg) {
    return arg;
}

template<typename T, typename... Args>
T average(T arg, Args... args) {
    return arg + average(args...) * (sizeof...(args) / (sizeof...(args) + 0.0));
}

int main() {
    cout << "Average of 2, 4, 6, 8, 10: " << average(2, 4, 6, 8, 10) << endl;
    cout << "Average of 1.2, 3.4, 5.6, 7.8: " << average(1.2, 3.4, 5.6, 7.8) << endl;
    cout << "Average of -3, -1, 1, 3: " << average(-3, -1, 1, 3) << endl;

    return 0;
}


Explanation:

This program demonstrates the use of template functions to calculate the average of any number of values. The average function is defined with a variable number of arguments, using the variadic template syntax typename... Args.

The first version of the average function takes a single argument of type T, which is returned directly. This serves as the base case for the recursion.

The second version of the average function takes two or more arguments, with the first argument of type T and the remaining arguments of type Args.... It recursively calls average on the remaining arguments, passing them as a pack expansion with the syntax args.... The function then calculates the weighted average of the arguments using the formula arg + average(args...) * (sizeof...(args) / (sizeof...(args) + 0.0)), where sizeof...(args) is the number of arguments in the pack expansion, and 0.0 is used to ensure the division is performed as a floating point operation.

In main(), the average function is called with different types of arguments - integers, floating-point numbers, and negative integers - and their average values are printed using cout.
