Exercise for reference: template function that can find the minimum value in an array of any data type.

Answer:


#include <iostream>
using namespace std;

template <typename T>
T findMin(T arr[], int n) {
    T minVal = arr[0];
    for (int i = 1; i < n; i++) {
        if (arr[i] < minVal) {
            minVal = arr[i];
        }
    }
    return minVal;
}

int main() {
    int intArr[] = {5, 3, 1, 8, 6};
    double doubleArr[] = {3.2, 1.5, 4.6, 7.8, 2.1};
    char charArr[] = {'B', 'A', 'D', 'C', 'E'};

    cout << "Minimum value in int array: " << findMin(intArr, 5) << endl;
    cout << "Minimum value in double array: " << findMin(doubleArr, 5) << endl;
    cout << "Minimum value in char array: " << findMin(charArr, 5) << endl;

    return 0;
}

Explanation:

This is a C++ program that demonstrates the use of a template function to find the minimum value in an array of any data type. The function takes two parameters: an array of type T and its size n. It returns the minimum value in the array.

The findMin function works by initializing the minimum value to the first element of the array. It then iterates over the remaining elements of the array, checking if each element is smaller than the current minimum value. If it is, the minimum value is updated to that element.

The main function declares three arrays of different data types and passes them to the findMin function. The minimum value of each array is printed to the console using cout.

Overall, this program demonstrates how templates can be used to write generic code that can work with any data type.
