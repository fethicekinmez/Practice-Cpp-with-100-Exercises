Question: Write a C++ program to implement a stack using a linked list


Expected output:

Initially, we push three elements onto the stack: 5, 10, and 15. The display function is then called to print the elements of the stack, which are printed in reverse order since we are using a linked list and treating the head as the top of the stack. Therefore, the output shows "15 10 5".

Next, we call the pop function to remove the top element (15) from the stack. The display function is called again to print the updated elements of the stack, which now only has two elements: 10 and 5. Therefore, the output shows "10 5".


15 10 5
10 5

Hint:

  • You can define a node structure that contains the data and a pointer to the next node in the list.

  • To create a stack, you can define a top pointer that points to the head of the linked list.

  • To push an element onto the stack, you can create a new node and make it the new head of the linked list. The next pointer of the new node should point to the previous head of the list.

  • To pop an element from the stack, you can delete the current head of the list and make the next node the new head of the list.

  • To display the elements of the stack, you can traverse the linked list starting from the head and print each element as you go.

  • You should also handle stack underflow (i.e., trying to pop from an empty stack) and display a message to the user if it occurs.

  • When the program ends, you should delete all nodes in the linked list to prevent memory leaks.
