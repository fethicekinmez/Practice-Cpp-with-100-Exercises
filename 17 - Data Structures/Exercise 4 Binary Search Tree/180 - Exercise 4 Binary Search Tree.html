Question: Implement a C++ program to insert nodes in a Binary Search Tree (BST) recursively and perform inorder traversal to display the nodes in sorted order.

Expected output:


20
30
40
50
60
70
80

Hint:

  1. Create a class BST with data, left and right pointers.

  2. Implement a default constructor and parameterized constructor to initialize the data, left and right pointers.

  3. Implement an insert function to insert a node in the BST recursively.

  4. In the insert function, check if the root is null, create a new node with the given value and return it.

  5. If the given value is greater than the root data, insert it in the right subtree recursively.

  6. If the given value is less than the root data, insert it in the left subtree recursively.

  7. Implement an inorder function to perform inorder traversal of the BST recursively.

  8. In the inorder function, traverse the left subtree recursively, display the data of the current node and traverse the right subtree recursively.

  9. Create an object of the BST class, insert nodes in the BST and display the nodes in sorted order using inorder traversal.
