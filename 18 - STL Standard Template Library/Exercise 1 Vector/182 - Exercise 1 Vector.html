Expected output:

Hint:

  • The vector container is a part of the C++ Standard Template Library (STL) and provides dynamic array-like functionality. It automatically adjusts its size as elements are added or removed.

  • The push_back method is used to add elements to the end of a vector.

  • The size method returns the current number of elements in the vector.

  • The begin method returns an iterator pointing to the first element in the vector.

  • The end method returns an iterator pointing just beyond the last element in the vector.

  • The * operator is used with an iterator to dereference it and retrieve the value stored at the current position.

  • The ++ operator is used with an iterator to advance it to the next position in the vector.
