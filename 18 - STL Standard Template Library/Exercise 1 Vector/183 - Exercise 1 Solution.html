Exercise for reference: The program to demonstrates the use of a vector

Answer:


#include <iostream>
#include <vector>
using namespace std;
 
int main() {

   // create a vector to store int
   vector<int> vec; 
   int i;

   // display the original size of vec
   cout << "vector size = " << vec.size() << endl;

   // push 5 values into the vector
   for(i = 0; i < 5; i++) {
      vec.push_back(i);
   }

   // display extended size of vec
   cout << "extended vector size = " << vec.size() << endl;

   // access 5 values from the vector
   for(i = 0; i < 5; i++) {
      cout << "value of vec [" << i << "] = " << vec[i] << endl;
   }

   // use iterator to access the values
   vector<int>::iterator v = vec.begin();
   while( v != vec.end()) {
      cout << "value of v = " << *v << endl;
      v++;
   }

   return 0;
}


Explanation:

This C++ code demonstrates the use of a vector, which is a dynamic array that can resize itself during runtime.

The code starts by creating an empty vector of integers using the vector<int> vec syntax. It then displays the size of the vector, which is initially 0, using the vec.size() function.

Next, the code uses a for loop to add five integer values to the vector using the vec.push_back(i) function.

After adding the values, the code displays the extended size of the vector, which should now be 5.

The code then uses two different methods to display the values stored in the vector. First, it uses a for loop to access the values directly using the vec[i] syntax. Second, it uses a while loop and an iterator to access the values indirectly. The vector<int>::iterator v = vec.begin() syntax creates an iterator that points to the beginning of the vector, and the v != vec.end() condition checks if the iterator has reached the end of the vector. The *v syntax dereferences the iterator and retrieves the value stored at the current position.
