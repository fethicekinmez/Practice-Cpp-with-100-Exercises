Exercise for reference: program that reads in a list of integers from the user and uses the std::accumulate function to compute the sum of the integers.

Answer:


#include <iostream>
#include <vector>
#include <numeric>

int main() {
    int n;
    std::cout << "Enter the number of integers: ";
    std::cin >> n;

    std::vector<int> nums(n);
    for (int i = 0; i < n; i++) {
        std::cout << "Enter integer #" << i + 1 << ": ";
        std::cin >> nums[i];
    }

    int sum = std::accumulate(nums.begin(), nums.end(), 0);

    std::cout << "The sum is: " << sum << std::endl;

    return 0;
}

Explanation:

The program reads in the number of integers to be input by the user, creates a vector to store the integers, reads in the integers one by one, and then uses the std::accumulate function to compute the sum of the integers. Finally, the sum is printed out to the console.
