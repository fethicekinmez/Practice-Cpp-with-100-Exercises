Question: Write a program that reads in a list of integers from the user and uses the std::partition function to partition the list into two parts: even numbers and odd numbers. Print out the modified list.



Expected output:


Enter the number of integers: 6
Enter integer #1: 1
Enter integer #2: 2
Enter integer #3: 3
Enter integer #4: 4
Enter integer #5: 5
Enter integer #6: 6
The modified list is: 2 4 6 1 3 5

Hint:

Use a std::vector to store the integers, and a lambda expression as the predicate for the std::partition function.
