Exercise for reference: program that reads in a list of integers from the user and uses the std::partition function to partition the list into two parts: even numbers and odd numbers. Print out the modified list.

Answer:


#include <iostream>
#include <vector>
#include <algorithm>

int main() {
    int n;
    std::cout << "Enter the number of integers: ";
    std::cin >> n;

    std::vector<int> nums(n);
    for (int i = 0; i < n; i++) {
        std::cout << "Enter integer #" << i + 1 << ": ";
        std::cin >> nums[i];
    }

    auto it = std::partition(nums.begin(), nums.end(), [](int n){ return n % 2 == 0; });

    std::cout << "The modified list is: ";
    for (auto i = nums.begin(); i != it; i++) {
        std::cout << *i << " ";
    }
    for (auto i = it; i != nums.end(); i++) {
        std::cout << *i << " ";
    }
    std::cout << std::endl;

    return 0;
}


Explanation:

The program reads in the number of integers to be input by the user, creates a vector to store the integers, reads in the integers one by one, and then uses the std::partition function to partition the vector into two parts: even numbers and odd numbers. The lambda expression (int n){ return n % 2 == 0; } is used as the predicate for the partition. Finally, the modified list is printed out to the console.
