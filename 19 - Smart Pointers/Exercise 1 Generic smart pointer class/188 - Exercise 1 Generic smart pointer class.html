Question: Write a C++program to swap two values using a template function.


Expected output:


20

Hint:

This program demonstrates a simple implementation of a smart pointer class. A smart pointer is a class that provides an interface similar to a regular pointer, but also manages the memory that the pointer is pointing to. In this case, the SmartPtr class manages an integer pointer. The * operator is overloaded to return the value of the integer that the pointer is pointing to, and the -> operator is overloaded to return the pointer itself. When the SmartPtr object goes out of scope, its destructor is called, which deletes the integer pointer and frees up the memory.
