Exercise for reference: he program demonstrates the use of unique_ptr

Answer:


#include <iostream>
#include <memory>
 
class Rectangle {
    int length;
    int breadth;
 
public:
    Rectangle(int l, int b){
        length = l;
        breadth = b;
    }
 
    int area(){
        return length * breadth;
    }
};
 
int main(){
 
    std::unique_ptr<Rectangle> P1(new Rectangle(10, 5));
    std::cout << P1->area() << std::endl; // This'll print 50
 
    std::unique_ptr<Rectangle> P2;
    P2 = std::move(P1);
 
    // This'll print 50
    std::cout << P2->area() << std::endl;
 
    // std::cout<<P1->area()<<std::endl; // this will give an error since P1 is now a null pointer
    return 0;
}


Explanation:

The program creates two instances of the Rectangle class using unique_ptr. The first instance is created with P1 and the second instance is created with P2. The area() function calculates and returns the area of the rectangle. The program first prints out the area of the first rectangle using the P1 pointer. Then, it transfers ownership of the first rectangle to the P2 pointer using the move function. Finally, it prints out the area of the second rectangle using the P2 pointer. Since the ownership of the first rectangle has been transferred to P2, attempting to print out the area using P1 would give a null pointer error.
