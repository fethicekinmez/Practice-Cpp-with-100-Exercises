Exercise for reference: The program that declares variables of various data types and prints their values in a specified format:.


Answer:


#include <iostream>
using namespace std;

int main() {
    int myInt = 42;
    double myDouble = 3.14159;
    float myFloat = 2.71828f;
    long int myLongInt = 1234567890;

    cout << "myInt: " << myInt << endl;
    cout << "myDouble: " << myDouble << endl;
    cout << "myFloat: " << myFloat << endl;
    cout << "myLongInt: " << myLongInt << endl;

    return 0;
}


Explanation:

The program declares variables of various data types and initializes them with values. Then, it uses the cout statement to print the values of these variables in a specified format. The endl statement is used to move to the next line after printing the value. Finally, the program returns 0 to indicate successful execution.
