Question: Write a C++ program to perform basic arithmetic operations on two integer variables.


Expected output: The program should output the result of adding, subtracting, multiplying, and dividing two integer variables, as well as their remainder after division, and the results of incrementing and decrementing the variables.


a + b is :16
a - b is :6
a * b is :55
a / b is :2
a % b is :1
a++ is :11
a-- is :12

Hint:

Basic arithmetic operations in C++ are performed using the following operators:

  • + addition

  • - subtraction

  • * multiplication

  • / division

  • % modulus (remainder after division)

  • ++ increment

  • -- decrement
