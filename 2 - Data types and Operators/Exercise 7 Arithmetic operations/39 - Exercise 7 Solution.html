Exercise for reference: C++ program to perform basic arithmetic operations on two integer variables.


Answer:


#include <iostream>
using namespace std;

int main() {
    int a = 11;
    int b = 5;
    int c;

    cout << "a + b is: " << a + b << endl; // 11 + 5 = 16

    cout << "a - b is: " << a - b << endl; // 11 - 5 = 6

    cout << "a * b is: " << a * b << endl; // 11 * 5 = 55

    cout << "a / b is: " << a / b << endl; // 11 / 5 = 2

    cout << "a % b is: " << a % b << endl; // 11 % 5 = 1

    cout << "a++ is: " << a++ << endl; // a is now 12

    cout << "a-- is: " << a-- << endl; // a is now 11

    return 0;
}


Explanation:

The program defines two integer variables a and b, with values of 11 and 5, respectively. The program then performs the following operations on these variables:

  • Addition: a + b

  • Subtraction: a - b

  • Multiplication: a * b

  • Division: a / b

  • Modulus: a % b

  • Increment: a++

  • Decrement: a--

The program outputs the results of each operation.
