Exercise for reference: C++ program to demonstrate the use of pre-increment and post-decrement operators


Answer:


#include <iostream>
using namespace std;

int main()
{
  int x = 4, y;
  y = ++x;
  cout << "PreIncrement: Value of x = " << x << endl;
  cout << "PreIncrement: Value of y = " << y << endl;

  y = x--;
  cout << "PostDecrement: Value of x = " << x << endl;
  cout << "PostDecrement: Value of y = " << y << endl;

  return 0;
}


Explanation:

The program defines two integer variables x and y, with the value of x set to 4. The program then demonstrates the use of the pre-increment and post-decrement operators by performing the following operations:

  • Pre-increment: y = ++x - the value of x is first incremented by 1, and then assigned to y.

  • Post-decrement: y = x-- - the value of x is first assigned to y, and then decremented by 1.

The program outputs the values of x and y before and after each operation.
