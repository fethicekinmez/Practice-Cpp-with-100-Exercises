Question: Write a C++ program to demonstrate the use of relational operators.


Expected output: The program should output whether the given conditions are true or false based on the values of two integer variables a and b.


a=11, b=5
a == b is false
a < b is false
a > b is true

Hint:


  • == operator checks if two values are equal.

  • < operator checks if the left value is less than the right value.

  • > operator checks if the left value is greater than the right value.
