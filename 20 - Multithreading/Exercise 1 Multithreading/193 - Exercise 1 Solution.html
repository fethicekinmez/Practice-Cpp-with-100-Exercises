Exercise for reference: program that creates two threads, each of which counts from 1 to 10. The threads should print out their count values as they go.

Answer:


#include <iostream>
#include <thread>

using namespace std;

void count(int thread_num) {
    for (int i = 1; i <= 10; i++) {
        cout << "Thread " << thread_num << ": " << i << endl;
    }
}

int main() {
    thread t1(count, 1);
    thread t2(count, 2);
    t1.join();
    t2.join();
    return 0;
}


Explanation:

The above code creates two threads t1 and t2 using the std::thread library. The count function is passed as a parameter to each of the threads, along with a thread number (1 for t1 and 2 for t2). The count function simply loops from 1 to 10 and prints out the thread number and count value. The main function waits for the threads to finish using the join() method, which ensures that the threads have completed before the program exits.
