Question: Write a program that creates a producer-consumer scenario using two threads. The producer thread should generate a random number between 1 and 100 every second and add it to a shared buffer. The consumer thread should read numbers from the buffer and print them out as they are read. The program should continue until the consumer thread has read 10 numbers from the buffer.

Expected output:

The program should output 10 random numbers between 1 and 100 that are read from the shared buffer by the consumer thread.
