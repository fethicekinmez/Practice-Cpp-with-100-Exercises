Exercise for reference: The program should output 10 random numbers between 1 and 100 that are read from the shared buffer by the consumer thread.

Answer:


#include <iostream>
#include <thread>
#include <chrono>
#include <mutex>
#include <condition_variable>
#include <queue>
#include <random>

std::mutex mtx;
std::condition_variable cv;
std::queue<int> buffer;

void producer()
{
    std::random_device rd;
    std::mt19937 gen(rd());
    std::uniform_int_distribution<int> dist(1, 100);
    while (true) {
        std::unique_lock<std::mutex> lock(mtx);
        int num = dist(gen);
        buffer.push(num);
        std::cout << "Producer produced " << num << std::endl;
        lock.unlock();
        cv.notify_one();
        std::this_thread::sleep_for(std::chrono::seconds(1));
    }
}

void consumer()
{
    int count = 0;
    while (count < 10) {
        std::unique_lock<std::mutex> lock(mtx);
        cv.wait(lock, [] { return !buffer.empty(); });
        int num = buffer.front();
        buffer.pop();
        std::cout << "Consumer consumed " << num << std::endl;
        lock.unlock();
        count++;
    }
}

int main()
{
    std::thread producer_thread(producer);
    std::thread consumer_thread(consumer);

    producer_thread.join();
    consumer_thread.join();

    return 0;
}


Explanation:

In this program, we create two threads: a producer thread and a consumer thread. The producer thread generates a random number between 1 and 100 every second and adds it to a shared buffer, which is implemented as a std::queue. The consumer thread reads numbers from the buffer and prints them out as they are read. The program continues until the consumer thread has read 10 numbers from the buffer.

To synchronize access to the shared buffer, we use a std::mutex and a std::condition_variable. The producer thread acquires the mutex, generates a random number, adds it to the buffer, and notifies the consumer thread using the condition variable. The consumer thread acquires the mutex, waits for the condition variable to be signaled (i.e., for the buffer to have at least one element), reads the first element from the buffer, prints it out, and releases the mutex. The program uses a count variable to keep track of the number of numbers that have been read from the buffer by the consumer thread.
