Question: Write a client-server program in C++ where the client sends a message to the server and the server sends back a response. Use sockets to establish the connection.


Expected output:

The client should send a message to the server and receive a response message from the server.


Client side:
Enter a message: Hello, server!
Server response: Message received!

Server side:
Client connected.
Message received from client: Hello, server!

Hint:

  • Use the socket library functions to establish the connection between the client and the server. Use send() function to send the message from the client to the server and use recv() function to receive the message from the server.
