Question: Write a C++ program When the user presses Ctrl+C, the program should print a message and terminate.


Expected output:


Hello, this is a signal handler example.
Press Ctrl+C to interrupt the program.
Hello World!
Hello World!
Hello World!
^C
Program interrupted by user.

Hint:

  • Use the signal() function to register the signal handler for SIGINT and define the signal handler function to print the message and exit the program.
