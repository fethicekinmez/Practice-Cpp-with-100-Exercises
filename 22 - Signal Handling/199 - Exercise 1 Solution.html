Exercise for reference: When the user presses Ctrl+C, the program should print a message and terminate.

Answer:


#include <csignal>
#include <iostream>
#include <cstdlib>

using namespace std;

void sigint_handler(int signal_num)
{
    cout << "Program interrupted by user." << endl;
    exit(signal_num);
}

int main()
{
    signal(SIGINT, sigint_handler);

    cout << "Hello, this is a signal handler example." << endl;
    cout << "Press Ctrl+C to interrupt the program." << endl;

    while (true) {
        cout << "Hello World!" << endl;
        sleep(1);
    }

    return 0;
}


Explanation:

The given program demonstrates the use of the signal() function in C++ to register a signal handler for the SIGABRT signal. The modified program registers a signal handler for the SIGINT signal and defines the sigint_handler() function to print a message and exit the program when the user presses Ctrl+C to interrupt the program. The program prints a message to inform the user about the expected behavior and enters an infinite loop to repeatedly print the "Hello World!" message. When the user presses Ctrl+C, the signal handler function is called to print the message and exit the program.
