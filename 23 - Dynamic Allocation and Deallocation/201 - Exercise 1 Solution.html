Exercise for reference: Modify the code to allocate and deallocate memory for an array of doubles.

Answer:


#include <iostream>
using namespace std;
 
int main ()
{
    // Pointer initialization to null
    double* p = NULL;
 
    // Request memory for the variable
    // using new operator
    p = new(nothrow) double;
    if (!p)
        cout << "allocation of memory failed\n";
    else
    {
        // Store value at allocated address
        *p = 13;
        cout << "Value of p: " << *p << endl;
    }
 
    // Request block of memory
    // using new operator
    double *r = new double(75.25);
 
    cout << "Value of r: " << *r << endl;
 
    // Request block of memory of size n
    int n = 5;
    double *q = new(nothrow) double[n];
 
    if (!q)
        cout << "allocation of memory failed\n";
    else
    {
        for (int i = 0; i < n; i++)
            q[i] = i+1;
 
        cout << "Value stored in block of memory: ";
        for (int i = 0; i < n; i++)
            cout << q[i] << " ";
    }
 
    // freed the allocated memory
    delete p;
    delete r;
 
    // freed the block of allocated memory
    delete[] q;
 
    return 0;
}


Explanation:

The program initializes a double pointer p to NULL and then requests memory for a double variable using the new operator. If the memory allocation is successful, it stores a value of 13 in the allocated memory location and prints the value of p. It then requests memory for a float variable r using the new operator and initializes its value to 75.25. It also requests a block of memory for an array of double variables using the new operator and the array size n. If the memory allocation is successful, it stores values in the allocated memory locations and prints the array values. Finally, the program deallocates the dynamically allocated memory using the delete and delete[] operators for single variables and arrays respectively.
