Exercise for reference: he program defines a class Box and a friend function printLength that takes an object of the Box class as a parameter and returns the length of the box object after adding 10 to it.

Sample Output:

Answer:


#include <iostream>    
using namespace std;    
class Box    
{    
    private:    
        int length;    
    public:    
        Box(): length(0) { }    
        friend int printLength(Box); //friend function    
};    
int printLength(Box b)    
{    
    b.length += 10;    
    return b.length;    
}    
int main()    
{    
    Box b;    
    cout<<"Length of box: "<< printLength(b)<<endl;    
    return 0;    
}


Explanation:

In the given program, a Box class is defined with a private data member length and a default constructor. A friend function printLength is declared in the class which takes an object of Box as a parameter and adds 10 to its length.

The printLength function is defined outside the class and accesses the private data member length of the Box object using the friend keyword, which allows the function to access private data members of the class.

In the main function, an object of Box is created and passed as an argument to the printLength function, which returns the length of the box after adding 10 to it. The returned value is then printed on the console.

The usage of a friend function in this program is to access the private data members of the Box class, which cannot be accessed by functions outside the class. The printLength function needs to access the length data member of the Box object to perform its task, so it is declared as a friend function in the Box class.
