Question: Write a c++ program asks the user to enter the size of a square and then prints out a square made of asterisks, with sides of length equal to the size entered by the user.


Expected output:

If the user enters a size of 3, the output of the program would be:


Enter the size of the square: 3
***
***
***

Hint:


  • The program uses a nested loop to print out the square.

  • The outer loop controls the rows of the square, while the inner loop controls the columns.

  • The program prints an asterisk * for each square in the overall square.
