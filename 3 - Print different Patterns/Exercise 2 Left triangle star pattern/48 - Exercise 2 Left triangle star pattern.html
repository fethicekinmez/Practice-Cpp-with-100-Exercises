Question: Write a C++ program to print the left triangle star pattern, where each row of the triangle has one more star than the previous row, and the perpendicular line of the triangle is on the left side.


Expected output: 


Enter the number of rows: 5
*
**
***
****
*****

Hint:

You can use nested loops to print the pattern. The outer loop controls the number of rows, and the inner loop controls the number of stars in each row.
