Exercise for reference: print the left triangle star pattern
Answer:


#include <iostream>
using namespace std;

int main() {
  int rows;
  cout << "Enter the number of rows: ";
  cin >> rows;

  // Outer loop to control the number of rows
  for (int i = 1; i <= rows; i++) {
    // Inner loop to print the stars in each row
    for (int j = 1; j <= i; j++) {
      cout << "*";
    }
    // Print a newline character to move to the next row
    cout << endl;
  }

  return 0;
}


Explanation:

The program uses a nested loop to print the left triangle star pattern. The outer loop runs from 1 to the number of rows entered by the user, and the inner loop runs from 1 to the current row number. In each iteration of the inner loop, the program prints an asterisk. After the inner loop is completed for the current row, the program prints a newline character to move to the next row.
