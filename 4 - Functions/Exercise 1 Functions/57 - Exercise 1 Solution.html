Exercise for reference: C++ program that takes two integers as input and performs basic arithmetic operations on them using separate functions.


Answer:


#include <iostream>

using namespace std;

int add(int a, int b) {
    return a + b;
}

int subtract(int a, int b) {
    return a - b;
}

int multiply(int a, int b) {
    return a * b;
}

int divide(int a, int b) {
    return a / b;
}

int main() {
    int num1, num2;

    cout << "Enter the first integer: ";
    cin >> num1;

    cout << "Enter the second integer: ";
    cin >> num2;

    cout << "The sum is: " << add(num1, num2) << endl;
    cout << "The difference is: " << subtract(num1, num2) << endl;
    cout << "The product is: " << multiply(num1, num2) << endl;
    cout << "The quotient is: " << divide(num1, num2) << endl;

    return 0;
}


Explanation:

Here's a breakdown of the program:

  1. First, the program includes the necessary header files (iostream) and uses the using namespace std statement to simplify the code.

  2. Next, the program defines four separate functions to perform the arithmetic operations: add(), subtract(), multiply(), and divide(). Each function takes two integer parameters and returns the result of the operation.

  3. The main() function prompts the user to enter two integers using the cout and cin statements, then calls each of the four arithmetic functions with the user-inputted integers and displays the result using the cout statement.

  4. The program ends with the return 0 statement, which signals to the operating system that the program has executed successfully.

By breaking the program down into separate functions for each arithmetic operation, the code becomes more modular and easier to read and understand. Additionally, this approach makes it easy to modify or extend the program in the future, such as by adding additional arithmetic operations.
