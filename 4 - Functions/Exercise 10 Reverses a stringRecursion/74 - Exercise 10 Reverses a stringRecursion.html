Question: Write a C++ program that recursively reverses a string:


Expected output::


Enter a string: Hello, world!
Reversed string: !dlrow ,olleH

Hint:

The reverseString function takes three parameters: a reference to the string to be reversed, the starting index (which initially should be 0), and the ending index (which initially should be str.length() - 1). If the starting index is greater than or equal to the ending index, the function returns without doing anything. Otherwise, it swaps the characters at the starting and ending indices, and then recursively calls itself with the starting index increased by 1 and the ending index decreased by 1.

In the main function, we take input from the user using the getline function (which allows us to read a whole line of input, including spaces), call reverseString with the input string and the starting and ending indices, and output the result.
