Exercise for reference: The program that recursively reverses a string


Answer:


#include <iostream>
#include <string>
using namespace std;

void reverseString(string& str, int start, int end) {
    if (start >= end) {
        return;
    }
    swap(str[start], str[end]);
    reverseString(str, start + 1, end - 1);
}

int main() {
    string str;
    cout << "Enter a string: ";
    getline(cin, str);
    reverseString(str, 0, str.length() - 1);
    cout << "Reversed string: " << str << endl;
    return 0;
}


Explanation:

Let's say the user enters the string "Hello, world!". When the reverseString function is called with this string and the starting index 0 and ending index 12 (which is the index of the last character in the string), it first checks if the starting index is greater than or equal to the ending index. Since it is not, the function swaps the characters at indices 0 and 12, resulting in the string "!ello, worldH". It then calls reverseString recursively with the starting index increased by 1 (which is now 1) and the ending index decreased by 1 (which is now 11), and continues this process until the entire string is reversed.
