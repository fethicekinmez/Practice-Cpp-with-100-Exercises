Question: Write a C++ program that takes a string as input and counts the number of vowels and consonants in the string using separate functions.


Expected output: 


Enter a string: Hello World!
Number of vowels: 3
Number of consonants: 8

Hint:

You can use two separate functions to count the number of vowels and consonants in the string. To check if a character is a vowel, you can use an if statement and check if it's equal to 'a', 'e', 'i', 'o', or 'u'.
