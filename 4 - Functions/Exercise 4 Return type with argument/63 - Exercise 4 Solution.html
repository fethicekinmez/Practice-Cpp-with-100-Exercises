Exercise for reference: The program should output the sum of the two input numbers.


Answer:


#include <iostream>

using namespace std;

int addNumbers(int num1, int num2) {
    int sum = num1 + num2;
    return sum;
}

int main() {
    int num1, num2;
    
    cout << "Enter the first number: ";
    cin >> num1;
    
    cout << "Enter the second number: ";
    cin >> num2;
    
    int sum = addNumbers(num1, num2);
    
    cout << "The sum of the two numbers is: " << sum << endl;
    
    return 0;
}


Explanation:

In this code, we first include the necessary header files to use iostream library. Then, we define a function addNumbers to add two numbers and return their sum. The function takes two input arguments - the two numbers to be added - and returns their sum.

In the main function, we ask the user to enter two numbers using the cin function. We then call the addNumbers function to calculate their sum and store the result in the sum variable. Finally, we print the sum using the cout function.
