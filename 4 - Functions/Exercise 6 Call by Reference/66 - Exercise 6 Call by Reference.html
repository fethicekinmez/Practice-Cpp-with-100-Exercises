Question: Write a C++ program to swap two numbers using call by reference.


Expected output: The program should output the values of the two input numbers after they have been swapped.


Before swapping:
a = 5
b = 7

After swapping:
a = 7
b = 5

Hint:

all by reference is a parameter passing mechanism where the reference (memory address) of the argument is passed to the function. The function then works with the original argument, and any changes made to the argument inside the function will affect the original argument. In this case, we will use call by reference to swap the values of two numbers.
