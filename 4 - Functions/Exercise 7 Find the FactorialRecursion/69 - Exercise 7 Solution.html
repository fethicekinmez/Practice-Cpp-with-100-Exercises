Exercise for reference: program to find the factorial of a given number using recursion.


Answer:


#include <iostream>
using namespace std;

int factorial(int n) {
   if (n == 1) {
       return 1;
   } else {
       return n * factorial(n-1);
   }
}

int main() {
   int n;
   cout << "Enter a positive integer: ";
   cin >> n;
   cout << "The factorial of " << n << " is " << factorial(n) << endl;
   return 0;
}


Explanation:

In this program, we define a function called factorial that takes an integer parameter n. If n is 1, the function returns 1 (the base case). Otherwise, the function multiplies n with the result of calling the factorial function with n-1 as the argument.
