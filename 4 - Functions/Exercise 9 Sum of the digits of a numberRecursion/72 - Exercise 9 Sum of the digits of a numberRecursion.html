Question: Write a C++ program that recursively calculates the sum of the digits of a number


Expected output::


Enter a number: 12345
Sum of digits: 15

Hint:

The recursive function digitSum takes an integer parameter n and returns the sum of its digits. If the number n is less than 10, the function returns the value of n. Otherwise, the function takes the modulo of n by 10 to get the last digit, adds it to the sum of the remaining digits (which is calculated by recursively calling digitSum with n/10), and returns the result.

In the main function, we take input from the user, call digitSum with the input value, and output the result.
