Exercise for reference: The program that recursively calculates the sum of the digits of a number


Answer:


#include <iostream>
using namespace std;

int digitSum(int n) {
    if (n < 10) {
        return n;
    } else {
        return (n % 10) + digitSum(n / 10);
    }
}

int main() {
    int num;
    cout << "Enter a number: ";
    cin >> num;
    cout << "Sum of digits: " << digitSum(num) << endl;
    return 0;
}


Explanation:

Let's say the user enters the number 12345. When the digitSum function is called with this value, it first checks if n is less than 10. Since it is not, the function takes the modulo of n by 10 to get the last digit, which is 5. It then calls digitSum recursively with n/10 (which is 1234), gets the sum of the remaining digits (which is 10), and adds it to 5 to get the final result, which is 15.
