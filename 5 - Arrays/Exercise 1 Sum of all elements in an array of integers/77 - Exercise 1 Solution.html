Exercise for reference: Program to find the sum of all elements in an array of integers.


Answer:


#include <iostream>
using namespace std;

int main() {
  int arr[] = {1, 2, 3, 4, 5};
  int n = sizeof(arr)/sizeof(arr[0]);
  int sum = 0;

  for(int i = 0; i < n; i++) {
    sum += arr[i];
  }

  cout << "The sum of the array is: " << sum << endl;

  return 0;
}


Explanation:

In this program, we first initialize an integer array arr with 5 elements. We then use the sizeof() function to find the number of elements in the array and store it in the integer variable n. We also initialize an integer variable sum to 0, which will be used to accumulate the sum of all the elements in the array.

Next, we use a for loop to iterate over all the elements in the array. Inside the loop, we add the current element of the array to the sum variable. Once the loop is complete, we output the value of sum to the console.
