Exercise for reference: The program should output the largest element in the array.


Answer:


#include <iostream>
using namespace std;

int main() {
   int arr[] = {5, 8, 1, 9, 3};
   int n = sizeof(arr) / sizeof(arr[0]);
   int maxVal = arr[0];

   for (int i = 1; i < n; i++) {
      if (arr[i] > maxVal) {
         maxVal = arr[i];
      }
   }

   cout << "The largest element in the array is: " << maxVal << endl;

   return 0;
}


Explanation:

To find the largest element in an array of integers, we can initialize a variable to store the maximum value to the first element in the array. Then, we can loop through the array and compare each element to the maximum value, updating the maximum value as necessary. Once we have looped through the entire array, the maximum value variable will contain the largest element.
