Question: Write a C++ program to reverse an array of integers.


Expected output::

For example, given the following array of integers:

int arr[] = {1, 2, 3, 4, 5};

The program should output:

The reversed array is: 5 4 3 2 1

Hint:

  • Start by finding the length of the array, which can be done by dividing the total size of the array by the size of each element.

  • Use a loop to swap the elements in the array. The loop should iterate from the first element to the middle element of the array.

  • Swap the elements at the current index and its corresponding element from the end of the array.

  • Keep swapping elements until the loop reaches the middle of the array.
