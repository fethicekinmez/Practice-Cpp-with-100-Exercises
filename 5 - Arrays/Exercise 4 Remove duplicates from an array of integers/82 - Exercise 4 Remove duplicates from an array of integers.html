Question: Write a program to remove duplicates from an array of integers.


Expected output:

For example, given the following array of integers:

int arr[] = {1, 2, 3, 2, 4, 5, 3};

The program should output:


Array after removing duplicates: 1 2 3 4 5


Hint: One way to remove duplicates from an array of integers is to use a nested loop to compare each pair of elements and shift the elements to the left if you find a duplicate.
