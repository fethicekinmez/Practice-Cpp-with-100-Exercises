Exercise for reference: program to remove duplicates from an array of integers


Answer:


#include <iostream>

using namespace std;

int main() {
    int arr[] = {1, 2, 3, 4, 5, 4, 3, 2, 1};
    int n = sizeof(arr) / sizeof(arr[0]);

    for (int i = 0; i < n; i++) {
        for (int j = i + 1; j < n; j++) {
            if (arr[i] == arr[j]) {
                // Shift the elements to the left
                for (int k = j; k < n - 1; k++) {
                    arr[k] = arr[k + 1];
                }
                n--;  // Decrement array size
                j--;  // Adjust inner loop index
            }
        }
    }

    cout << "Array after removing duplicates: ";
    for (int i = 0; i < n; i++) {
        cout << arr[i] << " ";
    }
    cout << endl;

    return 0;
}


Explanation:

  • In this program, we define an array of integers and find its size.

  • We then use two nested loops to compare each pair of elements in the array.

  • If we find a duplicate, we shift the elements to the left starting from the duplicate element.

  • We then decrement the array size to reflect the fact that we've removed an element.

  • We also adjust the index of the inner loop to account for the shifted elements.

  • Finally, we iterate through the array and print out its elements to verify that duplicates have been removed.
