Question: Write a C++ program to sort an array of integers in ascending order.


Expected output:

int arr[] = {3, 5, 1, 4, 2};


Sorted array in ascending order: 1 2 3 4 5

Hint:

One common algorithm to sort an array of integers in ascending order is called selection sort. This algorithm involves repeatedly finding the minimum element in the unsorted portion of the array and swapping it with the first element of that portion, until the entire array is sorted.
