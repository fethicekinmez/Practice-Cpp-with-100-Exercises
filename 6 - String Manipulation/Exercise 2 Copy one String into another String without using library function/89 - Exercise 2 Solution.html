Exercise for reference:  program that copies one string into another without using any library functions


Answer:


#include <iostream>

using namespace std;

int main() {
  char str1[] = "Hello, World!";
  char str2[100];
  int i = 0;
  
  // copy string1 into string2
  while (str1[i] != '\0') {
    str2[i] = str1[i];
    i++;
  }
  str2[i] = '\0';
  
  // print both strings
  cout << "String 1: " << str1 << endl;
  cout << "String 2: " << str2 << endl;
  
  return 0;
}


Explanation:


  • First, we declare two character arrays str1 and str2. str1 is initialized with the string "Hello, World!" and str2 is empty.

  • Next, we declare an integer variable i and initialize it to 0.

  • We then use a while loop to iterate through the characters of str1. Inside the loop, we copy each character from str1 to str2 at the corresponding index.

  • After the loop, we add a null character \0 at the end of str2 to terminate the string.

  • Finally, we use the cout statement to print both strings to the console.
