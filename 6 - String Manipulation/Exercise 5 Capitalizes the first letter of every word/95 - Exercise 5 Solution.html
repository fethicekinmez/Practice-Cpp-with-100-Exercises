Exercise for reference: program that takes a string input from the user and capitalizes the first letter of every word in the string:


Answer:


#include <iostream>
#include <string>

using namespace std;

int main() {
  string str;
  cout << "Enter a string: ";
  getline(cin, str);

  bool capitalize = true;
  for (int i = 0; i < str.length(); i++) {
    if (isspace(str[i])) {
      capitalize = true;
    } else if (capitalize) {
      str[i] = toupper(str[i]);
      capitalize = false;
    }
  }

  cout << "Capitalized string: " << str << endl;

  return 0;
}


Explanation:

  • First, we declare a string variable str and ask the user to enter a string using the getline function.

  • We then declare a boolean variable capitalize and initialize it to true.

  • We then use a for loop to iterate over every character in the string. If a space character is encountered, we set capitalize to true to indicate that the next character encountered should be capitalized. If a non-space character is encountered and capitalize is true, we use the toupper function to capitalize the character and set capitalize to false to indicate that the next character encountered should not be capitalized.

  • Finally, we print out the capitalized string to the console.
