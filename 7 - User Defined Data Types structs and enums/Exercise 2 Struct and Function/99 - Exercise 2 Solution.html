Exercise for reference: program that creates a struct to store information about a book, as well as two functions to prompt the user for the book's information and display the book's information


Answer:


#include <iostream>
#include <string>
using namespace std;

struct Book {
    string title;
    string author;
    int publication_year;
};

void inputBookInfo(Book& book) {
    cout << "Enter the book's title: ";
    getline(cin, book.title);
    cout << "Enter the book's author: ";
    getline(cin, book.author);
    cout << "Enter the book's publication year: ";
    cin >> book.publication_year;
}

void displayBookInfo(const Book& book) {
    cout << "Title: " << book.title << endl;
    cout << "Author: " << book.author << endl;
    cout << "Publication year: " << book.publication_year << endl;
}

int main() {
    Book myBook;
    inputBookInfo(myBook);
    cout << "\nBook information:\n";
    displayBookInfo(myBook);

    return 0;
}


Explanation:

In the main function, we create a Book struct called myBook. We then call the inputBookInfo function, passing in a reference to myBook, which prompts the user to enter the book's title, author, and publication year.

After the user enters the information, we call the displayBookInfo function, passing in a constant reference to myBook, which displays the book's information in the console.

In the inputBookInfo function, we use getline to read the title and author inputs, as getline is better suited to handle inputs that contain spaces.

Note that in the displayBookInfo function, we use a constant reference to the Book struct, as we do not want to modify its contents in this function.
