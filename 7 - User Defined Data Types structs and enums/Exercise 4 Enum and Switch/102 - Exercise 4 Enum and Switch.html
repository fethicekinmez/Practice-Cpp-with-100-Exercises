Question:  Write a c++ program that prompts the user to enter a number between 1 and 7, representing a day of the week, and then outputs a message indicating the weather for that day. Use the following mapping of days of the week to weather conditions:

  • Monday: sunny

  • Tuesday: cloudy

  • Wednesday: rainy

  • Thursday: snowy

  • Friday: partly cloudy

  • Saturday: thunderstorms

  • Sunday: foggy

Make sure to handle invalid input by outputting an error message.

Expected output:


Enter a number between 1 and 7: 3
Don't forget your umbrella. It's going to rain today.

Hint:

You can use an enum to represent the different days of the week and the different types of weather.

  • Use a switch statement to map the user's input to the corresponding day of the week and weather condition.

  • Don't forget to handle invalid input (i.e. numbers outside the range of 1 to 7) by outputting an error message.
