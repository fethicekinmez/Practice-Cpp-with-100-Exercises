Exercise for reference: Define a new data type named "Temp" using the typedef keyword that is an alias for the data type double. Write a program that declares two variables of type Temp named temp1 and temp2, and initializes them with the values 25.5 and 32.0, respectively. Calculate the average temperature of temp1 and temp2 and store it in a variable named avgTemp. Finally, print out the values of temp1, temp2, and avgTemp


Answer:


#include <iostream>

typedef double Temp;

int main() {
    Temp temp1 = 25.5;
    Temp temp2 = 32.0;
    Temp avgTemp = (temp1 + temp2) / 2.0;

    std::cout << "Temperature 1: " << temp1 << std::endl;
    std::cout << "Temperature 2: " << temp2 << std::endl;
    std::cout << "Average Temperature: " << avgTemp << std::endl;

    return 0;
}


Explanation:

In this exercise, we are using typedef to define a new data type named Temp that is an alias for the data type double. We then declare two variables of type Temp named temp1 and temp2, and initialize them with the values 25.5 and 32.0, respectively. We calculate the average temperature using the formula (temp1 + temp2) / 2.0, and store the result in a variable named avgTemp. Finally, we print out the values of temp1, temp2, and avgTemp
