Question: Write a C++ program that demonstrates how to declare, initialize, and use pointers to basic data types such as integers and floats.


Expected output: The program should output the values of the variables and their corresponding memory addresses.


x = 10
y = 3.14
&x = 0x7ffee6e26a6c
&y = 0x7ffee6e26a68
p = 0x7ffee6e26a6c
*q = 10

Hint:


  • A pointer is a variable that stores the memory address of another variable.

  • The & operator can be used to get the memory address of a variable.

  • The * operator can be used to declare a pointer and to access the value stored at the memory address it points to.

  • Pointers can be used to pass parameters by reference to a function, which allows the function to modify the original value of the parameter.

  • Pointers can also be used to dynamically allocate memory, which is useful when the amount of memory needed is not known at compile time.
