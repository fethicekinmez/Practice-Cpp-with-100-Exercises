Exercise for reference: The program should output the values of the variables and their corresponding memory addresses.


Answer:


#include <iostream>  // Includes the standard input/output library

using namespace std;  // Allows us to use cout, endl, and other functions in the std namespace

int main() {  // The main function that is executed when the program runs

    int x = 10;  // Declares an integer variable named x and initializes it with the value 10
    float y = 3.14;  // Declares a floating-point variable named y and initializes it with the value 3.14

    int* p = &x;  // Declares a pointer to an integer named p and initializes it with the memory address of x
    float* q = &y;  // Declares a pointer to a floating-point number named q and initializes it with the memory address of y

    cout << "x = " << x << endl;  // Outputs the value of x to the console
    cout << "y = " << y << endl;  // Outputs the value of y to the console
    cout << "&x = " << &x << endl;  // Outputs the memory address of x to the console
    cout << "&y = " << &y << endl;  // Outputs the memory address of y to the console
    cout << "p = " << p << endl;  // Outputs the value of the pointer p to the console (which is the memory address of x)
    cout << "*q = " << *q << endl;  // Outputs the value stored at the memory address pointed to by q (which is the value of y)

    return 0;  // Indicates successful program completion
}


Explanation:

This program declares two variables, x and y, and initializes them with values 10 and 3.14, respectively. It also declares two pointers, p and q, and initializes them with the memory addresses of x and y, respectively. The program then outputs the values of x and y, their memory addresses, and the values stored at the memory addresses pointed to by p and q. Finally, the program returns 0 to indicate successful completion.
