Exercise for reference: The program should output the values of the two variables after they have been swapped.


Answer:


#include <iostream>
using namespace std;

int main() {
    int x = 5;
    int y = 10;
    int *p = &x;
    int *q = &y;
    
    int temp = *p;
    *p = *q;
    *q = temp;
    
    cout << "x = " << x << endl;
    cout << "y = " << y << endl;
    
    return 0;
}


Explanation:

In this program, we declare two integer variables x and y, and two pointers to integers p and q. We then use the pointers to swap the values of x and y.

To swap two variables using pointers, we first need to declare pointers to those variables. We then use the pointers to access the values of the variables and swap them.

In this program, we use the following steps to swap the variables:


  1. Declare the variables and pointers:

int x = 5;
int y = 10;
int *p = &x;
int *q = &y;

  1. Swap the values using pointers:

int temp = *p;
*p = *q;
*q = temp;

  1. Output the values of the variables:

cout << "x = " << x << endl;
cout << "y = " << y << endl;

The output should be:

x = 10
y = 5
