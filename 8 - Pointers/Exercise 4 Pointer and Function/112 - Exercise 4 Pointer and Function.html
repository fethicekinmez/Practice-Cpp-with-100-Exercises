Question: Write a C++ program to find the sum of an array using pointers and functions.


Expected output: The program should output the sum of the array elements.


Enter the size of the array: 5
Enter the array elements: 1 2 3 4 5
The sum of the array is: 15

Hint:

Declare an integer array and a pointer to integers. Pass the array and its size as arguments to a function. In the function, use a pointer to traverse the array and add the elements. Return the sum to the main function and output it.
