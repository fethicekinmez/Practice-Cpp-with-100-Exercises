Exercise for reference: The program should output the value of the member variable and call the member function of the object using pointers.


Answer:


#include <iostream>
using namespace std;

class MyClass {
public:
    int myVar;
    void myFunc() {
        cout << "Hello from myFunc" << endl;
    }
};

int main() {
    MyClass obj;
    obj.myVar = 42;
    obj.myFunc();

    MyClass *ptr = &obj;
    cout << "myVar = " << ptr->myVar << endl;
    ptr->myFunc();

    return 0;
}


Explanation:

Pointers in C++ are variables that hold the memory address of another variable. They are used to access and manipulate the data stored in memory. Objects are instances of a class that contain member variables and member functions. Pointers to objects can be used to access the member variables and member functions of the object.
