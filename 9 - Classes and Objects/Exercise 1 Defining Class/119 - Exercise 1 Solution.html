Exercise for reference: Define a class called "Person" that has two attributes: "name" (a string) and "age" (an integer). In the main function, create an object of the "Person" class, set the values for the attributes, and print them out.


Answer:


#include <iostream>
#include <string>

using namespace std;

class Person {
  public:
    string name;
    int age;
};

int main() {
  Person myPerson;
  myPerson.name = "John";
  myPerson.age = 25;
  cout << myPerson.name << endl;
  cout << myPerson.age << endl;
  return 0;
}


Explanation:

The program defines a class called "Person" with two attributes: "name" (a string) and "age" (an integer). The main function creates an object of the "Person" class, sets the values for the attributes, and then prints them out using the dot notation to access the attributes of the object.
