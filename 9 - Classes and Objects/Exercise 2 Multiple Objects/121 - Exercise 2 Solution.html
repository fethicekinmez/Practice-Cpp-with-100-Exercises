Exercise for reference: Define a class called "Book" that has three attributes: "title" (a string), "author" (a string), and "year" (an integer). In the main function, create two objects of the "Book" class, set the values for their attributes, and print them out.


Answer:


#include <iostream>
#include <string>

using namespace std;

class Book {
  public:
    string title;
    string author;
    int year;
};

int main() {
  Book book1;
  book1.title = "The Catcher in the Rye";
  book1.author = "J.D. Salinger";
  book1.year = 1951;

  Book book2;
  book2.title = "To Kill a Mockingbird";
  book2.author = "Harper Lee";
  book2.year = 1960;

  cout << book1.title << " by " << book1.author << " (" << book1.year << ")\n";
  cout << book2.title << " by " << book2.author << " (" << book2.year << ")\n";
  return 0;
}


Explanation:

The program defines a class called "Book" with three attributes: "title" (a string), "author" (a string), and "year" (an integer). The main function creates two objects of the "Book" class, sets the values for their attributes, and then prints them out using the dot notation to access the attributes of the objects.
