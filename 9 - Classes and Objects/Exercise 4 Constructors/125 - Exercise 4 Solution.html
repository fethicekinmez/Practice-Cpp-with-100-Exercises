Exercise for reference: Define a class called Person with two private data members firstName and lastName. Define a public constructor to initialize these data members when an object of the Person class is created. In the main function, create an instance of the Person class called myPerson with firstName="John" and lastName="Doe", and print the full name of the person.

Answer:


#include <iostream>
#include <string>
using namespace std;

class Person {
  private:
     string firstName;
     string lastName;

  public:
    Person( string fn,  string ln) {
      firstName = fn;
      lastName = ln;
    }

     string getFullName() {
      return firstName + " " + lastName;
    }
};

int main() {
  Person myPerson("John", "Doe");
   cout << "Full Name: " << myPerson.getFullName() <<  endl;
  return 0;
}


Explanation:

  • We define a class called Person with two private data members firstName and lastName.

  • We define a public constructor to initialize these data members when an object of the Person class is created.

  • In the main function, we create an instance of the Person class called myPerson with firstName="John" and lastName="Doe".

  • We call the getFullName method on the myPerson object to retrieve the full name of the person.
